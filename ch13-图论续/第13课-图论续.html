1　色数 χ：最少要几种颜色？

幻灯片 662–668

把每门考试画成一个点。如果有学生同时选了两门课，就在那两个点之间连边。给每个点填一个时段，边的两端必须填不同的时段。换成颜色来想，一个时段就是一种颜色。

正常点着色要求每条边的两端异色。手里有 k 种颜色、允许有些颜色闲置，这叫 k-着色。能办到的最小 k 就是色数 χ(G)。

同色点之间没有边，所以每个颜色类都是一个独立集。

要证明 χ(G) = 3，就做两件事。先解释两种颜色为什么不够，再实际给出一种三色涂法。

例｜五边形 C5　如果只有两种颜色，从 A 开始沿圈就只能交替涂成 1、2、1、2、1。最后一个点和 A 相邻，两端都是 1，矛盾。改成 1、2、1、2、3 就合法，所以 χ(C5) = 3。

这个证明也适用于所有奇圈（练习 #598）。偶圈可以一直交替着色，色数为 2。更一般地，有至少一条边的图，色数为 2 当且仅当它是二部图。

要证明从哪里下手
至少用 r 色找 Kr：其中每两个点都相邻，每个点都得用不同颜色。找奇圈也能证明至少需要 3 色。
至多用 r 色写出每个点的颜色，逐边检查。也可以按某个顺序贪心着色。

贪心着色：先看已经涂好的邻居

先给顶点排个顺序。轮到一个点时，记下它的已着色邻居用了哪些色号，再选没有被占用的最小色号。如果最大度数为 Δ，每次至多有 Δ 个邻居挡住颜色，因此χ(G) ≤ Δ + 1。

在同一个六边形上换顺序

圆周顺次连着 A–B–C–D–E–F–A。节点内的数字是色号。

六边形沿圈顺次贪心只用 2 色。若先涂 A、D、B，它们依次拿到 1、1、2。轮到 C 时，邻居 B 和 D 已占了 2 和 1，于是必须开第 3 色。做题时，贪心结果能用来给出上界，下界要另找理由。

Brooks 定理（幻灯片 668）　连通图若既不是完全图也不是奇圈，则 χ(G) ≤ Δ。这里的 Δ 界来自定理，任意顺序的贪心只保证 Δ + 1。

2　色多项式：给定 k 种颜色，有几种涂法？

幻灯片 668–673

用 PG(k) 表示合法着色的总数。颜色有编号，交换 1 号和 2 号可能会得到另一种涂法。例如一条边用两色有 2 种涂法，因为两端谁拿 1 号都可以。能使 PG(k) > 0 的最小非负整数 k 就是色数。

图色多项式为什么
n 个孤立点 Nnkn每个点可随意选色。
完全图 Kn[k]n = k(k−1)⋯(k−n+1)第 j 个点避开前面 j−1 个点的颜色。
n 个点的树k(k−1)n−1从根向外涂。根有 k 种选法，每个非根点避开父节点的颜色即可。

删除—收缩：先允许同色，再减掉同色

在图 G 上选一条边 e = uv。删边 G−e 时，所有顶点保留。缩边 G/e 时，把 u 和 v 合成一个点，去掉被缩的边并合并重边。

删边后，合法涂法分成两类。

  1. u、v 异色。把边接回去仍然合法，这一类有 PG(k) 种。
  2. u、v 同色。把两个同色点捏成一个点，刚好对应缩边图的涂法，这一类有 PG/e(k) 种。

PG(k) = PG−e(k) − PG/e(k)

例｜四边形 C4　对边 DA 做删除—收缩。删边得到四点路径 A–B–C–D，缩边得到三角形 (AD)–B–C–(AD)。

PC₄(k) = k(k−1)3 − k(k−1)(k−2)

取 k = 3 时，路径有 24 种涂法，其中 6 种让 A 与 D 同色。接回 DA 后留下 18 种。

对照四边形的三个图

反复拆下去，遇到无边图就写 k顶点数。遇到树和完全图可直接用表里的式子。删边保留点数，缩边少一个点。用这个观察对边数归纳，可以看出 n 点图的色多项式次数是 n，最高次项系数为 1。

几块图只共用一个团时，怎样直接拼起来？

假设删掉公共团 S = Kr 后，图分成 t 块。每块把 S 加回来，得到 H1 到 Ht。先固定公共团的具体配色。由于颜色编号可以互换，每块在这个固定配色下的扩展方案数都是 PHᵢ(k) / [k]r，各块可独立选择。最后乘回公共团自己的 [k]r 种涂法。

PG(k) = PH₁(k) ⋯ PHₜ(k) / ([k]r)t−1

除式按多项式化简后，再代入具体的 k。例如两个三角形共用一条边，可先涂公共边，再各涂自己的第三个点，得到 k(k−1)(k−2)2。同理，若 G 含 Kr，其色多项式有因子 [k]r。各连通分支完全分开时，色多项式直接相乘，色数取最大值。

3　平面图：能不能把交叉消掉？

幻灯片 662、674–677

平面图（planar graph）可以画在平面上，使边只在共同的端点相遇。这样的一个具体画法叫平面嵌入，画出来的图叫平面表示（plane graph）。判断平面性时允许挪动点、弯曲边，保留原来的相邻关系。

右图有 3 个内部小三角形，加上外面无限延伸的一块，一共 4 个面（讲义称区域）。所以这里的点数 n = 4、边数 e = 6、面数 f = 4，恰好 4 − 6 + 4 = 2。

Euler 公式　连通平面嵌入满足 n − e + f = 2。

从一棵生成树开始。树有 n−1 条边，只有外面一个面，式子是 n − (n−1) + 1 = 2。沿原画法添回每条非树边时，点数不变，一条边把一个面切成两个，e 和 f 各加 1。

数面边界时逐侧数边。 每条边有两侧，所以所有面的边界长度加起来等于 2e。一条桥的两侧属于同一个面，也要各数一次。例如一条两边的路径，只有外面一个面，边界长度为 4。

从数面得到边数上限　连通简单平面图有 n ≥ 3 时，每个面的边界长度至少为 3，所以 3f ≤ 2e。将 f = 2 − n + e 代入，得 e ≤ 3n − 6。若还是二部图，面边界长度为偶数且至少 4，改用 4f ≤ 2e，得 e ≤ 2n − 4。

K5 有 5 点 10 边，超过 3·5 − 6 = 9，因此非平面。K3,3 有 6 点 9 边，超过二部图上限 2·6 − 4 = 8，因此也非平面。

边数超过上限就能判非平面。满足上限时还要继续检查，例如 K3,3 满足普通的 3n − 6 界。想证明平面，最直接的办法是画出一个没有交叉的嵌入。

遇到加了中间点的 K5 或 K3,3 怎么办？

把边 uv 改为路径 u–x–v，其中 x 是新点，这叫细分。在已有的边上放一个点，或者擦掉这个点再把两段线接上，都可以沿同一条轨迹进行，因此细分保留平面性。

Kuratowski 定理说，一个图是平面图，当且仅当它没有任何子图是 K5 或 K3,3 的细分。另一个等价判据是看能否通过删点、删边和缩边得到这两个图之一（Wagner 定理）。找细分时，代表不同原边的路径不能共用内部点。

4　五色定理：五种颜色都被占了怎么办？

幻灯片 676、678–680

地图上每个区域画成一个顶点，共享一段边界的区域连边。只在一个点接触的区域可以同色。这样地图着色就变成了平面图的点着色。

五色定理　每个简单平面图都可以用至多 5 种颜色正常着色。

先删一个点，涂好剩下的图

对连通的简单平面图，n ≥ 3 时，平均度数 2e/n ≤ 6 − 12/n < 6，所以至少一个顶点 x 的度数至多为 5。不到 3 点时可直接着色，不连通时可逐块着色。删掉 x 得到更小的平面图，对顶点数归纳，先把它五着色。若 x 的邻居没用满五色，就用剩下的一色涂 x。

五个邻居恰好五色时，整块换色

先记住一个操作。只保留两种颜色（比如 1 和 3）及这些点之间的边，取所得导出子图的一个连通分支，把这个分支里的 1、3 对调。这叫 Kempe 换色。分支内部两端一起换，仍然异色。跨出分支的边若通向另一种 1 或 3，那个点本来就会在同一个分支里。故跨出的邻居只能是其他色，换完依然合法。

  1. 在平面画法上绕 x 一圈，依次把五个邻居叫作 y1 到 y5，把它们的颜色编号记作 1 到 5。
  2. 如果 y1 和 y3 在删掉 x 后没有通过 1、3 色的路径相连，就换 y1 所在的 1、3 色分支。y1 变成 3 色，1 色空出来给 x。
  3. 如果有这条 1、3 色路径，它和 xy1、xy3 围成一个圈，把 y2 与 y4 分在两侧。2、4 色路径不能经过这个圈上的点，也不能穿过它的边，因此连不到另一侧。换 y2 所在的 2、4 色分支，2 色空出来给 x。

联系　四色定理把上界改进为 4。讲义还介绍了 Hadwiger 猜想：若 χ(G) ≥ p，则 G 含 Kp 作为子式（也称图的 minor），也就是可以通过删点、删边和缩边得到 Kp。其中 p = 5 的情形等价于四色定理。

5　独立集、团与支配集：挑出的点要满足什么？

幻灯片 681–690

点集怎么检查求什么
独立集集合里面每两个点都没有边。最大大小 α(G)
团集合里面每两个点都有边。最大大小 ω(G)
支配集集合外每个点都至少有一个邻居在集合里面。最小大小 dom(G)

同一个五边形 C5　沿圈标 A、B、C、D、E。A、C 可以一起选进独立集，又能支配全图。沿圈每个已选点后至少要空一个点，5 个顶点放不下 3 个独立点，所以 α = 2。一条边的两个端点构成团，图中没有三角形，所以 ω = 2。任一个点连自己最多覆盖 3 点，因此 dom = 2。

一个独立集如果再也加不进点，就称为极大独立集。它必定支配所有外面的点，否则还能把某个未被支配的点加进来。比如三点路径 A–M–B 中，{M} 已经极大，{A, B} 才是大小最大的独立集。

对至少有两个顶点的连通图，可取一棵生成树。树的二部划分中，较小那一侧至多 ⌊n/2⌋ 个点，而且每个另一侧的点至少和它相邻一次，于是 dom(G) ≤ ⌊n/2⌋。

独立集和团都能给色数下界。 每种颜色装得下至多 α(G) 个点，于是 χ(G) ≥ ⌈n/α(G)⌉。一个团里的所有点都得异色，于是 χ(G) ≥ ω(G)。

在补图 G 里，原来相连的点对不相连，原来不相连的点对变成相连。因此 α(G) = ω(G)。若用 θ(G) 表示把顶点划分成团所需的最少团数，则 θ(G) = χ(G) ≥ α(G)。

讲义用八皇后举例：每个格子是一个点，两个格子的皇后会互相攻击就连边。能同时摆多少个互不攻击的皇后，就是求 α。每行至多摆一个给出了上界 8，找出一组能摆 8 个的方案就达到了上界。

区间图、弦图和完美图

  • 区间图。每个点是一段时间，两段闭区间只要有公共点就连边。例如 [1, 3] 和 [3, 5] 在 3 相交，所以对应的点相邻。
  • 弦图。长度至少为 4 的每个圈都有弦，也就是圈上两个不连续点之间有一条边。比如单独一个四边形没有弦，加上一条对角线就成了弦图。
  • 完美图。对它的每一个导出子图 H，都有 χ(H) = ω(H)。C5 的色数为 3，团数为 2，所以只要某个导出子图是 C5，整个图就不完美。

区间图 ⊆ 弦图 ⊆ 完美图。

想象一个由区间排成的长圈，找右端点最靠左的那个区间。圈上它的两个邻居都必须含这个右端点，因此两个邻居相交，连出的边就是一条弦。

为什么弦图也完美？

讲义给了一个拆图方法。连通弦图中，按包含关系极小的割集会诱导出一个团。沿着这个团拆开，对每个小块分别着色，再通过颜色重新编号让各块在公共团上的颜色一致，就能拼回整图。用顶点数归纳，各块用到的色数都等于各自的最大团大小，所以整图的色数也等于最大团大小。完全图作起点，不连通的图可以分开涂。弦图的导出子图仍是弦图，因此每个导出子图也满足这个等式。

讲义也给出完美图的两个判别结果。完美图的补图仍完美。强完美图定理还说明，完美当且仅当图和它的补图都没有长度至少为 5 的无弦奇圈作为导出子图。

6　连通度：最少要删几个点或几条边？

幻灯片 691–696

都连通的图也可能有不同的抗断能力。只允许删点和只允许删边，是两个分别计算的问题。删点会同时删掉它关联的所有边。

记号怎么数
κ(G)点连通度。对非完全图，数让剩余图不连通至少要删几个顶点。约定 κ(Kn) = n − 1。
λ(G)边连通度。数保留全部顶点时，让图不连通至少要删几条边。
δ(G)最小度数。找一个邻居最少的点，记录它的度数。

对至少有两个顶点的图有 κ(G) ≤ λ(G) ≤ δ(G)。把度数最小的点的所有边删掉就能孤立它，所以 λ ≤ δ。已经不连通的图，κ 和 λ 都是 0。

让两个共用一个点的三角形断开

三角形 ABX 和 CDX 只共用 X。删掉 X 就断开，所以 κ = 1。任删一条边，每个三角形都还连通。删 AX 和 AB 可以孤立 A，所以 λ = 2。这个例子的 δ 也等于 2。删掉就使连通图断开的顶点叫割点，这样的边叫桥。这里 X 是割点，每条边都在三角形上，因此图没有桥。

两点之间能不能绕一道？

当 n ≥ 3 时，2-连通就是图连通且没有割点。下面两种说法也等价。

  • 任意两个不同的点 a 和 b 都在某个共同的圈上。
  • 从 a 到 b 有两条路，内部顶点互不重叠。把一个经过 a 和 b 的圈沿两点分开，就得到这两条路。

推广到 k ≥ 1、n ≥ k + 1 时，k-连通（κ ≥ k）等价于每对不同顶点之间有 k 条内部顶点互不重叠的路。理解其中一个方向：删不到 k 个别的顶点，至少还有一条路没被截断。

块：把图拆成没有割点的部分

块是再也扩不大的、连通且内部没有割点的导出子图。一个连通图（至少有两点）的块要么是桥形成的 K2，要么是 2-连通图。上例中，两个三角形各是一个块。它们能共用割点 X，但边各归一个块。一般地，两个不同块最多共用一个点，所有块的边集划分了原图的边集。

#604、#605　从 Kn（n ≥ 2）删掉一条边 uv，求色数和色多项式。

展开解答

除了 u 和 v，每对点仍然相邻。去掉 v 能看到一个 Kn−1，至少要 n − 1 色。让 v 用和 u 一样的色，n − 1 色就够了。

计数分两类。若 u、v 异色，等同给 Kn 涂色，共 [k]n 种。若它们同色，可以当成一个点，共 [k]n−1 种。总数为 [k]n + [k]n−1。

#608　证明 PCₙ(k) = (k − 1)n + (−1)n(k − 1)，其中 n ≥ 3。

展开解答

n = 3 时，三角形用 k(k−1)(k−2)，也等于 (k−1)3 − (k−1)。对于 n ≥ 4，删掉圈的一条边得到 n 点路径，收缩它得到 Cn−1。

PCₙ(k) = k(k−1)n−1 − PCₙ₋₁(k)

代入 Cn−1 的式子后，前两项合成 (k−1)n，余下的项因减号变为 (−1)n(k−1)。

再练平面图

#617　连通简单平面图若 e = 3n − 6，证明任一平面嵌入的每个面都有三条边作为边界。

展开解答

把 e = 3n − 6 代入 Euler 公式，就有 2e = 3f。每个面的边界至少长 3，所有面的边界加起来刚好是 3f，所以每个面都只能正好长 3。外部面也算在内。

#620、#621　简单平面图若每点度数一样，证明这个公共度数至多为 5。再证明任何至少有两个点的简单平面图都有至少两个度数至多为 5 的点。

展开解答

若 n ≤ 2，每个点度数至多为 1。其余情况有总度数 2e ≤ 6n−12。即使图不连通，也可以在各连通分支之间加边而不破坏平面性，再对加边后的图用边数上界。

#620 中，如果所有度数都至少为 6，总和至少为 6n，矛盾。#621 中，如果至多一个点的度数 ≤ 5，其他至少 n−1 个点各贡献 6 度，总度数至少为 6n−6，同样矛盾。

最后用点集和连通度收尾

#627　证明 n 点树的独立数至少是 ⌈n/2⌉。

展开解答

以一个点为根，按到根的距离的奇偶性分成两组。树的任意一条边都连接相邻层，所以两个组分别是独立集。较大的一组至少有 ⌈n/2⌉ 个点。

#639　证明二部图都是完美图。

展开解答

任取一个导出子图 H，保留二部划分后它仍是二部图。若 H 有边，两端构成大小为 2 的团，且两色就够了，所以 χ(H) = ω(H) = 2。若 H 有点无边，两个数都等于 1。无顶点时二者都是 0。

#643、#649　举一个 κ < λ 的例子。再说明树的每个块为什么都是 K2（树至少有两个点）。

展开解答

两个三角形只共用一个点的图就满足 κ = 1 < λ = 2。对树，任一有三个或更多顶点的连通导出子图仍是树。它有一个度数至少为 2 的点，删掉这个点就断成几块，所以这个子图有割点。于是能成为块的只有各条边形成的 K2。
