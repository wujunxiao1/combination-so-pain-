## #333（Brualdi 7.30）用生成函数解递推关系

**题目**：用 7.5 节介绍的生成函数方法解下列递推关系：

- (i) hₙ = 4hₙ₋₂ (n ≥ 2)；h₀ = 0，h₁ = 1
- (ii) hₙ = hₙ₋₁ + hₙ₋₂ (n ≥ 2)；h₀ = 1，h₁ = 3
- (iii) hₙ = hₙ₋₁ + 9hₙ₋₂ − 9hₙ₋₃ (n ≥ 3)；h₀ = 0，h₁ = 1，h₂ = 2
- (iv) hₙ = 8hₙ₋₁ − 16hₙ₋₂ (n ≥ 2)；h₀ = −1，h₁ = 0
- (v) hₙ = 3hₙ₋₂ − 2hₙ₋₃ (n ≥ 3)；h₀ = 1，h₁ = 0，h₂ = 0
- (vi) hₙ = 5hₙ₋₁ − 6hₙ₋₂ − 4hₙ₋₃ + 8hₙ₋₄ (n ≥ 4)；h₀ = 0，h₁ = 1，h₂ = 1，h₃ = 2

**统一方法**：设 g(x) = Σₙ≥₀ hₙxⁿ。把递推写成 hₙ − c₁hₙ₋₁ − ⋯ − cₖhₙ₋ₖ = 0，则 g(x)·(1 − c₁x − ⋯ − cₖxᵏ) 中 xⁿ (n ≥ k) 的系数全为 0，只剩一个次数 < k 的多项式（由初值算出）。于是 g(x) 是有理函数，部分分式分解后用

  1/(1−ax) = Σ aⁿxⁿ，  1/(1−ax)² = Σ (n+1)aⁿxⁿ，  1/(1−ax)³ = Σ C(n+2,2)aⁿxⁿ

读出 hₙ。

### (i)

g(x)(1 − 4x²) = h₀ + h₁x + Σₙ≥₂(hₙ − 4hₙ₋₂)xⁿ = 0 + x = x，所以

  g(x) = x / [(1−2x)(1+2x)] = A/(1−2x) + B/(1+2x)。

x = A(1+2x) + B(1−2x)：令 x = 1/2 得 1/2 = 2A，A = 1/4；令 x = −1/2 得 −1/2 = 2B，B = −1/4。

  g(x) = (1/4)·1/(1−2x) − (1/4)·1/(1+2x)

  **hₙ = [2ⁿ − (−2)ⁿ] / 4**（即 n 偶时 hₙ = 0，n 奇时 hₙ = 2ⁿ⁻¹）。

检验：h₁ = (2+2)/4 = 1 ✓，h₃ = (8+8)/4 = 4 = 4h₁ ✓。

### (ii)

g(x)(1 − x − x²) = h₀ + (h₁ − h₀)x = 1 + 2x。

1 − x − x² = (1−αx)(1−βx)，其中 α = (1+√5)/2，β = (1−√5)/2（α + β = 1，αβ = −1，α − β = √5）。

  g(x) = (1+2x) / [(1−αx)(1−βx)] = A/(1−αx) + B/(1−βx)，

1 + 2x = A(1−βx) + B(1−αx)。
令 x = 1/α：1 + 2/α = A(1 − β/α)，两边乘 α 得 α + 2 = A(α − β) = √5·A，A = (α+2)/√5 = (5+√5)/(2√5) = (1+√5)/2 = α。
再由常数项 A + B = 1 得 B = 1 − α = β。

  g(x) = α/(1−αx) + β/(1−βx)

  **hₙ = αⁿ⁺¹ + βⁿ⁺¹ = ((1+√5)/2)ⁿ⁺¹ + ((1−√5)/2)ⁿ⁺¹**

检验：h₀ = α + β = 1 ✓；h₁ = α² + β² = (α+β)² − 2αβ = 1 + 2 = 3 ✓。（数列为 1, 3, 4, 7, 11, 18, …）

### (iii)

g(x)(1 − x − 9x² + 9x³) = h₀ + (h₁ − h₀)x + (h₂ − h₁ − 9h₀)x² = x + x²。

分解：1 − x − 9x² + 9x³ = (1−x) − 9x²(1−x) = (1−x)(1−3x)(1+3x)。

  g(x) = (x + x²) / [(1−x)(1−3x)(1+3x)] = A/(1−x) + B/(1−3x) + C/(1+3x)。

x + x² = A(1−3x)(1+3x) + B(1−x)(1+3x) + C(1−x)(1−3x)：
- 令 x = 1：2 = A·(−2)(4)，A = −1/4；
- 令 x = 1/3：4/9 = B·(2/3)(2)，B = 1/3；
- 令 x = −1/3：−2/9 = C·(4/3)(2)，C = −1/12。

  hₙ = −1/4 + (1/3)·3ⁿ − (1/12)(−3)ⁿ，即

  **hₙ = [4·3ⁿ − (−3)ⁿ − 3] / 12**

检验：h₀ = (4−1−3)/12 = 0 ✓，h₁ = (12+3−3)/12 = 1 ✓，h₂ = (36−9−3)/12 = 2 ✓，h₃ = (108+27−3)/12 = 11 = h₂ + 9h₁ − 9h₀ ✓。

### (iv)

g(x)(1 − 8x + 16x²) = h₀ + (h₁ − 8h₀)x = −1 + 8x，1 − 8x + 16x² = (1−4x)²。

  g(x) = (−1 + 8x)/(1−4x)² = A/(1−4x) + B/(1−4x)²，

−1 + 8x = A(1−4x) + B：比较 x 的系数 −4A = 8，A = −2；常数项 A + B = −1，B = 1。

  g(x) = −2/(1−4x) + 1/(1−4x)² = Σ [−2·4ⁿ + (n+1)4ⁿ] xⁿ

  **hₙ = (n − 1)·4ⁿ**

检验：h₀ = −1 ✓，h₁ = 0 ✓，h₂ = 16 = 8·0 − 16·(−1) ✓。

### (v)

g(x)(1 − 3x² + 2x³) = h₀ + h₁x + (h₂ − 3h₀)x² = 1 − 3x²。

分解：1 − 3x² + 2x³ = (1−x)²(1+2x)（展开 (1 − 2x + x²)(1 + 2x) = 1 − 3x² + 2x³ 验证）。

  g(x) = (1 − 3x²) / [(1−x)²(1+2x)] = A/(1−x) + B/(1−x)² + C/(1+2x)，

1 − 3x² = A(1−x)(1+2x) + B(1+2x) + C(1−x)²：
- 令 x = 1：−2 = 3B，B = −2/3；
- 令 x = −1/2：1/4 = C·(9/4)，C = 1/9；
- 令 x = 0：1 = A + B + C，A = 1 + 2/3 − 1/9 = 14/9。

  hₙ = 14/9 − (2/3)(n+1) + (1/9)(−2)ⁿ，即

  **hₙ = [8 − 6n + (−2)ⁿ] / 9**

检验：h₀ = 9/9 = 1 ✓，h₁ = (8−6−2)/9 = 0 ✓，h₂ = (8−12+4)/9 = 0 ✓，h₃ = (8−18−8)/9 = −2 = 3h₁ − 2h₀ ✓。

### (vi)

g(x)(1 − 5x + 6x² + 4x³ − 8x⁴) = h₀ + (h₁ − 5h₀)x + (h₂ − 5h₁ + 6h₀)x² + (h₃ − 5h₂ + 6h₁ + 4h₀)x³
= 0 + x − 4x² + 3x³ = x(1−x)(1−3x)。

分解分母：特征多项式 r⁴ − 5r³ + 6r² + 4r − 8 有根 r = 2（16 − 40 + 24 + 8 − 8 = 0）和 r = −1（1 + 5 + 6 − 4 − 8 = 0），除以 (r−2)(r+1) = r² − r − 2 得 r² − 4r + 4 = (r−2)²，所以 r⁴ − 5r³ + 6r² + 4r − 8 = (r−2)³(r+1)，相应地

  1 − 5x + 6x² + 4x³ − 8x⁴ = (1−2x)³(1+x)。

  g(x) = x(1−x)(1−3x) / [(1−2x)³(1+x)] = A/(1+x) + B/(1−2x) + C/(1−2x)² + D/(1−2x)³，

x − 4x² + 3x³ = A(1−2x)³ + B(1+x)(1−2x)² + C(1+x)(1−2x) + D(1+x)：
- 令 x = −1：−1 − 4 − 3 = −8 = 27A，A = −8/27；
- 令 x = 1/2：1/2 − 1 + 3/8 = −1/8 = (3/2)D，D = −1/12；
- 比较 x³ 的系数：3 = −8A + 4B，4B = 3 − 64/27 = 17/27，B = 17/108；
- 比较常数项：0 = A + B + C + D，C = 8/27 − 17/108 + 1/12 = (32 − 17 + 9)/108 = 2/9。

于是

  hₙ = −(8/27)(−1)ⁿ + (17/108)2ⁿ + (2/9)(n+1)2ⁿ − (1/12)·C(n+2,2)·2ⁿ。

化简 2ⁿ 的系数：[34 + 48(n+1) − 9(n+1)(n+2)]/216 = (64 + 21n − 9n²)/216，所以

  **hₙ = [2ⁿ(64 + 21n − 9n²) − 64·(−1)ⁿ] / 216**

检验：h₀ = (64 − 64)/216 = 0 ✓，h₁ = (2·76 + 64)/216 = 1 ✓，h₂ = (4·70 − 64)/216 = 1 ✓，h₃ = (8·46 + 64)/216 = 2 ✓，h₄ = (16·4 − 64)/216 = 0 = 5·2 − 6·1 − 4·1 + 8·0 ✓。

## #340（Brualdi 7.37）hₙ = C(n,2) 的生成函数

**题目**：设数列 h₀, h₁, h₂, …, hₙ, … 由 hₙ = C(n,2)（n ≥ 0）定义。求它的生成函数。

**解答**

由牛顿二项式定理（负指数）：

  1/(1−x)³ = Σₖ≥₀ C(k+2, 2) xᵏ。

两边乘 x²：

  x²/(1−x)³ = Σₖ≥₀ C(k+2, 2) xᵏ⁺² = Σₙ≥₂ C(n, 2) xⁿ（令 n = k + 2）。

又 h₀ = C(0,2) = 0，h₁ = C(1,2) = 0，所以

  g(x) = Σₙ≥₀ C(n,2) xⁿ = **x² / (1−x)³**。

检验：x²(1 + 3x + 6x² + 10x³ + ⋯) = x² + 3x³ + 6x⁴ + 10x⁵ + ⋯，系数 0, 0, 1, 3, 6, 10 正是 C(n,2) ✓。

## #350（Brualdi 7.47）用递推关系重新推导 hₙ = (5ⁿ + 2·3ⁿ + 1)/4

**题目**：我们已经用指数生成函数证明了：每位数字都是奇数、且数字 1 和 3 都出现偶数次的 n 位数个数为

  hₙ = (5ⁿ + 2·3ⁿ + 1)/4 (n ≥ 0)。

请另给一种推导：先找出 hₙ 满足的递推关系，再解这个递推关系。

**解答**

可用数字为 1, 3, 5, 7, 9（都非 0，所以 n 位数就是这 5 个数字组成的长度为 n 的串）。对长度为 m 的串，按 1 和 3 出现次数的奇偶性分三类：

- hₘ：1、3 都出现偶数次；
- uₘ：1、3 中恰有一个出现奇数次；
- cₘ：1、3 都出现奇数次。

显然 hₘ + uₘ + cₘ = 5ᵐ，h₀ = 1，c₀ = 0。

**第 1 步：按最后一位分类，得递推。**

长度为 n 的串属于 hₙ 类，当且仅当：
- 最后一位是 5、7、9（3 种），前 n−1 位属于 hₙ₋₁ 类；或
- 最后一位是 1，前 n−1 位中 1 奇、3 偶；或最后一位是 3，前 n−1 位中 1 偶、3 奇。这两种合起来正好是 uₙ₋₁ 类的全部。

所以 hₙ = 3hₙ₋₁ + uₙ₋₁。同理（最后一位是 1 时前面须 1 偶 3 奇，是 3 时前面须 1 奇 3 偶）cₙ = 3cₙ₋₁ + uₙ₋₁。

**第 2 步：消去 uₙ₋₁ 和 cₙ₋₁。**

两式相减：hₙ − cₙ = 3(hₙ₋₁ − cₙ₋₁)，而 h₀ − c₀ = 1，所以 hₙ − cₙ = 3ⁿ，即 cₙ = hₙ − 3ⁿ。

于是 uₙ₋₁ = 5ⁿ⁻¹ − hₙ₋₁ − cₙ₋₁ = 5ⁿ⁻¹ − 2hₙ₋₁ + 3ⁿ⁻¹，代入 hₙ = 3hₙ₋₁ + uₙ₋₁ 得

  **hₙ = hₙ₋₁ + 5ⁿ⁻¹ + 3ⁿ⁻¹ (n ≥ 1)，h₀ = 1。**

**第 3 步：解递推。** 逐项累加：

  hₙ = h₀ + Σₖ₌₀ⁿ⁻¹ (5ᵏ + 3ᵏ) = 1 + (5ⁿ − 1)/4 + (3ⁿ − 1)/2 = (4 + 5ⁿ − 1 + 2·3ⁿ − 2)/4

  **hₙ = (5ⁿ + 2·3ⁿ + 1)/4**，与指数生成函数的结果一致。∎

检验：h₁ = 3（只有 5、7、9），公式 (5 + 6 + 1)/4 = 3 ✓；h₂ = h₁ + 5 + 3 = 11，公式 (25 + 18 + 1)/4 = 11 ✓。

## #352（Brualdi 8.1）圆上 2n 个点两两连线互不相交的方法数是 Cₙ

**题目**：在圆上取 2n 个（等距的）点。证明：把这些点两两配对连成 n 条线段、且这些线段互不相交的方法数等于第 n 个卡特兰数 Cₙ。

**解答**

设 aₙ 为所求方法数，约定 a₀ = 1（0 个点只有"什么都不连"一种）。注意 aₙ 只与点的个数有关（只用到点在圆周上的先后顺序），与点的具体位置无关。

**第 1 步：建立递推。** 把点按顺时针编号 1, 2, …, 2n。看点 1 与哪个点 k 相连。线段 1k 把其余点分成两部分：

- 弧上的点 2, 3, …, k−1，共 k−2 个；
- 弧上的点 k+1, …, 2n，共 2n−k 个。

因为线段互不相交，一侧的点不能与另一侧的点相连（否则那条线段与 1k 相交），所以两侧各自内部配对，且各自内部线段也互不相交。于是 k−2 必须是偶数，记 k − 2 = 2j（j = 0, 1, …, n−1），则一侧有 2j 个点、另一侧有 2(n−1−j) 个点。

反过来，两侧各任取一种不相交连法，再加上线段 1k，得到的连法仍然互不相交（两侧的线段分别在 1k 的两边，不会相交，也不与 1k 相交）。所以 k = 2j+2 时有 aⱼ·aₙ₋₁₋ⱼ 种。由加法原理：

  **aₙ = Σⱼ₌₀ⁿ⁻¹ aⱼ aₙ₋₁₋ⱼ = a₀aₙ₋₁ + a₁aₙ₋₂ + ⋯ + aₙ₋₁a₀ (n ≥ 1)，a₀ = 1。**

**第 2 步：与卡特兰数比较。** 卡特兰数满足完全相同的递推和初值：

  Cₙ = C₀Cₙ₋₁ + C₁Cₙ₋₂ + ⋯ + Cₙ₋₁C₀ (n ≥ 1)，C₀ = 1。

由数学归纳法：a₀ = C₀ = 1；若 aⱼ = Cⱼ 对所有 j < n 成立，则 aₙ = Σ aⱼaₙ₋₁₋ⱼ = Σ CⱼCₙ₋₁₋ⱼ = Cₙ。故对所有 n，

  **aₙ = Cₙ = C(2n, n)/(n+1)。** ∎

检验：n = 1, 2, 3, 4 时 aₙ = 1, 2, 5, 14（程序枚举所有配对后数出），与 Cₙ 一致。

> **注**（若老师要求从"±1 序列"定义出发）：Brualdi 把 Cₙ 定义为 n 个 +1、n 个 −1 组成、所有部分和 ≥ 0 的序列个数。也可直接建双射：从点 1 走到点 2n，每条线段的先到端点记 +1、后到端点记 −1。每个 −1 前面都有它配对的 +1，所以部分和 ≥ 0；反过来，从左到右把每个 −1 与它前面最近的尚未配对的 +1 配对，就唯一还原出一种不相交连法（不相交 ⇔ 线段两端之间的点只在内部配对 ⇔ 这种"括号式"配对）。

## #355（Brualdi 8.4）由乘法方案求凸多边形的三角剖分

**题目**：求下列乘法方案所对应的凸多边形区域的三角剖分：

- (i) (a₁ × (((a₂ × a₃) × (a₄ × a₅)) × a₆))
- (ii) (((a₁ × a₂) × (a₃ × (a₄ × a₅))) × ((a₆ × a₇) × a₈))

**对应规则**：n 个数的乘法方案对应 n+1 边形的三角剖分。把凸 (n+1) 边形的顶点依次记为 P₀, P₁, …, Pₙ，边 Pᵢ₋₁Pᵢ 标为 aᵢ（i = 1, …, n），剩下的边 PₙP₀ 作为"底边"，表示最终乘积。方案中的每个中间乘积 aᵢaᵢ₊₁⋯aⱼ 对应对角线 **Pᵢ₋₁Pⱼ**；每做一次乘法 (X × Y) 对应一个三角形，它的两条边是 X、Y，第三条边是 X×Y。

### (i)

6 个数 → 凸 **7 边形** P₀P₁⋯P₆，共 5 次乘法 → 5 个三角形、4 条对角线。

| 中间乘积 | 对应对角线 |
|---|---|
| a₂a₃ | P₁P₃ |
| a₄a₅ | P₃P₅ |
| (a₂a₃)(a₄a₅) = a₂a₃a₄a₅ | P₁P₅ |
| (a₂⋯a₅)a₆ = a₂⋯a₆ | P₁P₆ |
| a₁(a₂⋯a₆)（最终乘积） | 底边 P₆P₀ |

**三角剖分**：对角线 P₁P₃、P₃P₅、P₁P₅、P₁P₆，把 7 边形分成 5 个三角形：

  △P₁P₂P₃（a₂×a₃），△P₃P₄P₅（a₄×a₅），△P₁P₃P₅（(a₂a₃)×(a₄a₅)），△P₁P₅P₆（(a₂⋯a₅)×a₆），△P₀P₁P₆（a₁×(a₂⋯a₆)）。

### (ii)

8 个数 → 凸 **9 边形** P₀P₁⋯P₈，共 7 次乘法 → 7 个三角形、6 条对角线。

| 中间乘积 | 对应对角线 |
|---|---|
| a₁a₂ | P₀P₂ |
| a₄a₅ | P₃P₅ |
| a₃(a₄a₅) = a₃a₄a₅ | P₂P₅ |
| (a₁a₂)(a₃a₄a₅) = a₁⋯a₅ | P₀P₅ |
| a₆a₇ | P₅P₇ |
| (a₆a₇)a₈ = a₆a₇a₈ | P₅P₈ |
| (a₁⋯a₅)(a₆a₇a₈)（最终乘积） | 底边 P₈P₀ |

**三角剖分**：对角线 P₀P₂、P₃P₅、P₂P₅、P₀P₅、P₅P₇、P₅P₈，把 9 边形分成 7 个三角形：

  △P₀P₁P₂（a₁×a₂），△P₃P₄P₅（a₄×a₅），△P₂P₃P₅（a₃×(a₄a₅)），△P₀P₂P₅（(a₁a₂)×(a₃a₄a₅)），△P₅P₆P₇（a₆×a₇），△P₅P₇P₈（(a₆a₇)×a₈），△P₀P₅P₈（(a₁⋯a₅)×(a₆a₇a₈)）。

## #365（Brualdi 8.14）用第二类 Stirling 数表示 Σ kᵖ

**题目**：求出并验证 Σₖ₌₀ⁿ kᵖ 的一个用第二类 Stirling 数表示的一般公式。

**解答**

**结论**：对 p ≥ 1，

  **Σₖ₌₀ⁿ kᵖ = Σⱼ₌₁ᵖ S(p, j) · j! · C(n+1, j+1)**

（等价写法：Σⱼ S(p,j)·[n+1]ⱼ₊₁/(j+1)，其中 [m]ᵣ = m(m−1)⋯(m−r+1)。）

**第 1 步：kᵖ = Σⱼ C(k, j) · j! · S(p, j)。**

对一个 p 元集合 X 和一个 k 元集合 Y，从 X 到 Y 的函数共 kᵖ 个。按函数的像集大小 j 分类：
- 先选出像集（Y 的一个 j 元子集）：C(k, j) 种；
- 再数 X 到这 j 元集合的满射：把 X 分成 j 个非空无序块有 S(p, j) 种，再把 j 个块一一对应到像集的 j 个元素有 j! 种，共 j!·S(p, j) 种。

由加法、乘法原理，kᵖ = Σⱼ₌₀ᵖ C(k, j)·j!·S(p, j)。（p ≥ 1 时 S(p,0) = 0，j 从 1 起即可；当 j > k 时 C(k,j) = 0，公式自动成立。）

**第 2 步：对 k 求和，交换求和次序。**

  Σₖ₌₀ⁿ kᵖ = Σₖ₌₀ⁿ Σⱼ₌₁ᵖ S(p, j)·j!·C(k, j) = Σⱼ₌₁ᵖ S(p, j)·j!·[Σₖ₌₀ⁿ C(k, j)]。

**第 3 步：用"曲棍球棒"恒等式** Σₖ₌₀ⁿ C(k, j) = C(n+1, j+1)（由帕斯卡公式 C(k+1, j+1) = C(k, j+1) + C(k, j) 逐项相加、相邻项抵消得到）：

  Σₖ₌₀ⁿ kᵖ = Σⱼ₌₁ᵖ S(p, j)·j!·C(n+1, j+1)。∎

**验证**：

- p = 1：S(1,1) = 1，得 C(n+1, 2) = n(n+1)/2 ✓。
- p = 2：S(2,1) = S(2,2) = 1，得 C(n+1,2) + 2C(n+1,3) = n(n+1)/2 + (n+1)n(n−1)/3 = n(n+1)[3 + 2(n−1)]/6 = **n(n+1)(2n+1)/6** ✓。
- p = 3：S(3,1) = 1，S(3,2) = 3，S(3,3) = 1，得 C(n+1,2) + 6C(n+1,3) + 6C(n+1,4)。取 n = 2：3 + 6 + 0 = 9 = 1³ + 2³ ✓；取 n = 3：6 + 24 + 6 = 36 = 1 + 8 + 27 ✓（一般地等于 [n(n+1)/2]²）。

（程序已对 1 ≤ p ≤ 7、0 ≤ n ≤ 11 全部核对。）
