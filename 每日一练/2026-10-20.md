### 一、偏序、Hasse 图与线性扩展（样卷 3 题型）

**题 1** 判断下面每个关系是偏序、全序（线序）、等价关系，还是都不是：
(a) 正整数集上，a R b ⇔ a 整除 b；
(b) {1, 2, 3, 4} 上，a R b ⇔ a < b；
(c) {1, 2, 3, 4} 上，a R b ⇔ a ≤ b；
(d) 整数集上，a R b ⇔ a − b 是偶数。

**题 2** X = {2, 3, 4, 5, 6, 8, 10, 12}，按"a 整除 b"成为偏序集。写出全部覆盖关系，画出 Hasse 图，并找出所有极小元和极大元。

**题 3** 偏序集 {a, b, c, d, e} 只有这些关系：a < b < c，d < e（其余元素两两不可比）。
(a) 下面两个排列是不是线性扩展？a d b c e；a b e d c。
(b) 一共有多少个线性扩展？

**题 4（#208）** {a, b, c} 的全部 8 个子集按 ⊆ 成为偏序集。它一共有多少个线性扩展？

**题 5（等价关系）** (a) 在 {1, 2, …, 12} 上定义 a ~ b ⇔ 4 整除 a − b，写出所有等价类。
(b) {1, 2, 3, 4} 上一共有多少个不同的等价关系？（提示：等价关系 ⇔ 划分。）

### 三、"知道 / 不知道"逻辑推理（样卷 1.1 题型）

**题 9** C 告诉 A、B 自己的生日是下面 10 个日期之一，然后只把月份告诉 A，只把日子告诉 B。

| 月 \ 日 | 13 | 14 | 16 | 17 | 19 |
|---|---|---|---|---|---|
| **5** |   |   |   |   | ✓ |
| **6** |   |   | ✓ |   | ✓ |
| **7** | ✓ |   |   | ✓ | ✓ |
| **8** | ✓ | ✓ | ✓ | ✓ |   |

A："我不知道 C 的生日，但我知道 B 也不知道。"
B："一开始我不知道，但现在我知道了。"
A："现在我也知道了。"
C 的生日是哪天？每一句话排除了哪些日期？

**题 10** 同样的规则（A 知道月份，B 知道日子），这次的 10 个日期是：

| 月 \ 日 | 13 | 14 | 15 | 16 | 17 | 18 | 19 |
|---|---|---|---|---|---|---|---|
| **5** | ✓ | ✓ |   |   |   |   |   |
| **6** |   | ✓ | ✓ |   | ✓ |   |   |
| **7** |   |   |   | ✓ |   |   | ✓ |
| **8** |   | ✓ |   | ✓ |   | ✓ |   |

这次 B 先说话：
B："我不知道。"
A："我一开始也不知道，但现在我知道了。"
B："那我也知道了。"
C 的生日是哪天？
