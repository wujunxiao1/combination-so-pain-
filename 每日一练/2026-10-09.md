# 每日一练 2026-10-09 · 鸽巢原理：设计笼子

知识点：[第2课 鸽巢原理](https://claude.ai/artifact/1799LrXjTbKW7MSGF7dXTM) §1–2 简单形式

## 题目

**题 1（自编）** 从 {1, 2, …, 20} 中任意选 11 个数。
(a) 证明：一定有两个选出的数，它们的和等于 21。
(b) 如果只选 10 个数，这个结论还一定成立吗？

**题 2（#90）** 证明：任意给 n+1 个整数，其中一定有两个数，它们的差能被 n 整除。

## 我的作答

- 1(a)：笼子是 (1,20)、(2,19)…这样能凑成 21 的数对，共 10 个，选 11 个数放入对应的笼子，至少有一个笼子被填满。
- 1(b)：不一定成立，反例 1, 2, …, 10。
- 2：如果两个数除以 n 的余数相同，相减就能被 n 整除。n 个笼子是除以 n 余数为 0 到 n−1 的数，n 个笼子放 n+1 个数，一定有两个数余数相同，相减就能被 n 整除。

**全对 ✓**

## 答案与讲解

- 1(a) 笼子 {1,20}, {2,19}, …, {10,11} 共 10 个。11 个数必有两个在同一笼子，**这两个数的和为 21，证毕**（证明最后要把结论写出来）。
- 1(b) 不一定。{1,…,10} 中任意两数之和最大 9+10 = 19。说明 11 是"刚好够"的数量。
- 2 按除以 n 的余数分 n 个笼子。补一行"为什么"：设 a = q·n + r，b = p·n + r，则 a − b = (q − p)·n 是 n 的倍数。

套路：先想"什么样的两个数放在一起就能直接得到结论"，再按这个条件分笼子。

（题 1 用程序枚举了全部 C(20,11) 种选法核对。）
