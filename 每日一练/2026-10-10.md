## 题目

**题 1（自编）** 看 {1, 2, 3, 4, 5} 的排列 41352。
(a) 求它的逆序列 a₁, a₂, …, a₅（aⱼ = 排在 j 前面、并且比 j 大的数有几个）。
(b) 这个排列一共有几个逆序？

**题 2（#168 前半）** 每次只能交换相邻的两个数，要把排列 256143 变成 123456。
最少要交换几次？为什么不能更少？再写出一种具体的交换过程。

## 我的作答

- 1(a)：1, 4, 2, 0, 3
- 1(b)：4 个逆序
- 2：如果两个数是逆序的，将这两个相邻的数交换一次就会减少一个逆序对，因此最少就是 3+0+3+2+0+0 = 8 次。（疑问：如果逆序对不相邻，交换不能减少逆序对，需要更多次数？）

**题 1 有错，题 2 正确 ✓**

## 答案与讲解

**题 1** aⱼ 只数**排在 j 前面、而且比 j 大**的数（作答里把 j 前面所有数都数进去了）。排列 4 1 3 5 2：
- a₁：1 前面有 4，比 1 大 → 1
- a₂：2 前面有 4、1、3、5，比 2 大的是 4、3、5 → 3
- a₃：3 前面有 4、1，比 3 大的只有 4 → 1
- a₄：4 在最前面 → 0
- a₅：5 前面有 4、1、3，都比 5 小 → 0

逆序列 **1, 3, 1, 0, 0**；逆序数 = 1+3+1+0+0 = **5**。核对：逆序对 (4,1)、(4,3)、(4,2)、(3,2)、(5,2)，正好 5 对。

**题 2** 逆序列 3, 0, 3, 2, 0, 0，逆序数 8，最少 **8** 次。
1. 为什么不能更少：交换相邻的 x、y，只有这一对的先后变了，它们和其他数的先后关系都不变，所以逆序数**恰好变化 1**。从 8 到 0 至少 8 次。
2. 为什么 8 次一定够：只要还没排好，就一定有一对**相邻**的数是"大在前"（否则每对相邻都是小在前，整个排列已经有序）。每次交换这样一对，逆序数减 1。所以不会出现"逆序对都不相邻"的情况。

一种过程：256143 → 251643 → 251463 → 251436 → 215436 → 214536 → 214356 → 124356 → 123456

（答案均用程序核对。）
