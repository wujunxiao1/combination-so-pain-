## 答案与讲解

**题 1** x⁴y³ 的项：从 7 个括号里选 4 个出 2x、3 个出 −y：C(7,4)·2⁴·(−1)³ = **−560**。x³y⁴：C(7,3)·2³·(−1)⁴ = **280**。（C(7,4) = C(7,3)，两种写法都对。）

**题 2** 反过来用二项式定理 (a+b)ⁿ = Σ C(n,k) aⁿ⁻ᵏ bᵏ：每项 (−1)ᵏ·10ᵏ = (−10)ᵏ 是 b = −10，aⁿ⁻ᵏ"不见了"说明 a = 1。所以和 = (1 − 10)ⁿ = **(−9)ⁿ**。n = 2 验证：1 − 20 + 100 = 81 = (−9)²。

**题 3** 2ⁿ = (3 + (−1))ⁿ = Σ C(n,k)·3ⁿ⁻ᵏ·(−1)ᵏ，a = 3，b = −1，证毕。

**题 4** 套路：系数多一个 k → 求导；次数不对 → 乘 x；最后代值。
(1+x)ⁿ = Σ C(n,k)xᵏ → 求导：n(1+x)ⁿ⁻¹ = Σ kC(n,k)xᵏ⁻¹ → 乘 x：nx(1+x)ⁿ⁻¹ = Σ kC(n,k)xᵏ → 令 x = 2：**2n·3ⁿ⁻¹**。n = 2 验证：12。（x = 1 时就是第5课的 Σ kC(n,k) = n·2ⁿ⁻¹。）

**题 5** 52413：a₁ = 3（5、2、4），a₂ = 1（5），a₃ = 2（5、4），a₄ = 1（5），a₅ = 0。逆序列 **3, 1, 2, 1, 0**，逆序数 **7**。

（答案均用程序核对，恒等式对 n ≤ 11 逐一验证。）
