## 答案与讲解

**题 1：50 + 33 − 16 = 67。** 既是 2 的倍数又是 3 的倍数的数（6 的倍数）被数了两次，要减掉一次。

**题 2：5429。** S₁ = 2500 + 1666 + 1428 + 1000 = 6594。两两交集用最小公倍数：lcm(4,6)=12 → 833，lcm(4,7)=28 → 357，lcm(4,10)=20 → 500，lcm(6,7)=42 → 238，lcm(6,10)=30 → 333，lcm(7,10)=70 → 142，S₂ = 2403。三重：lcm(4,6,7)=84 → 119，lcm(4,6,10)=60 → 166，lcm(4,7,10)=140 → 71，lcm(6,7,10)=210 → 47，S₃ = 403。四重：lcm=420 → 23。答案 10000 − 6594 + 2403 − 403 + 23 = 5429。
求 lcm：分解质因数，每个质数取最高次幂。4 = 2²，6 = 2·3，所以 lcm(4,6) = 2²·3 = 12，不是 24。

**题 3：1000 − 1033 + 332 − 33 = 266。**

**题 4：S₁ − 2S₂ + 3S₃ = 1033 − 664 + 99 = 468。**
有 m 个性质的数在 Sₖ 里被数 C(m,k) 次。想让"恰好 1 个"的数算 1 次、其余算 0 次，系数就是 +1、−2、+3。不背公式也能拆块算：只被 2 整除 = 500 − (166 + 100 − 33) = 267，只被 3 = 134，只被 5 = 67，合计 468。
公式表：恰好 0 个 N − S₁ + S₂ − S₃；恰好 1 个 S₁ − 2S₂ + 3S₃；恰好 2 个 S₂ − 3S₃；恰好 3 个 S₃；至少 1 个 S₁ − S₂ + S₃。自检：恰好 0～3 个加起来等于 N。互动讲解页：[恰好 t 个怎么数](https://claude.ai/artifact/AedvyDN2wEsihgEtqY3GtT)

**题 5：7! − 5! − 6! + 4! = 4224。** 出现 ABC：捆成一块，剩 5 个元素 5!；出现 EF：6!；两个都出现：4!。

**题 6：6! − 3·5! + 3·4! − 3! = 426。** 三个条件，容斥要做到三重交集为止。

**题 7：10⁴ − 3·9⁴ + 3·8⁴ − 7⁴ = 204。**
"每个都至少出现一次"直接数很难，反过来设坏性质：A₀ = 没有 0，|A₀| = 9⁴（每位只能填另外 9 个数字）；两个都没有 8⁴；三个都没有 7⁴。题目要"一个坏性质都没有"。
为什么"选一个位置放 0，其他随便填"不对：0050 这种有多个 0 的串会被数多次。数"有 0"要用补集 10⁴ − 9⁴。

**题 8：30 − 2·12 + 6 = 12。** 总数 5!/(2!2!) = 30；aa 相邻：捆成一块，4!/2! = 12；aa、bb 都相邻：3! = 6。

**题 9：630 − 3·180 + 3·60 − 24 = 246。**

**题 10：Σₖ (−1)ᵏ C(5,k)·(10−k)!/2^(5−k) = 113400 − 113400 + 50400 − 12600 + 1800 − 120 = 39480。** 捆 k 对，剩 10−k 个元素，其中 5−k 对仍是相同字母。

**题 11：C(9,4) = 126。** 插空：8 天不游泳排一排，形成 9 个空，选 4 个空放游泳的天。隔板：8 个不游泳的天被 4 个游泳日分成 5 段，中间 3 段至少 1 天，先分掉 3 天，剩 5 天随便分到 5 段，C(5+4,4) = C(9,4)。盒子里装的只是不游泳的天。

**题 12：C(8,3) = 56。** 同一个小组里，"先选的那个人"可以是 3 人中任何一个，每组被数 3 次，168 = 3 × 56。

**题 13：C(10,5) = 252。** C(r,r) + C(r+1,r) + … + C(n,r) = C(n+1,r+1)。

**题 14：P(12,3)² = 1742400。** 红、黄、蓝依次选行 P(12,3)，再依次选列 P(12,3)。

**题 15：536142。** 从大到小放：6 放最前；5 前面有 0 个比它大，放在 6 前面得 56；4 前面有 2 个比它大，放在 6 后面得 564；3 前面有 1 个比它大，放在 5 后面得 5364；2 前面有 4 个比它大，放在最后得 53642；1 前面有 3 个比它大，放在 6 后面得 536142。
