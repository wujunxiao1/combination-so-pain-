### 三、"知道 / 不知道"逻辑推理（样卷 1.1 题型，原 10-20 题 9–10）

| 月 \ 日 | 13 | 14 | 16 | 17 | 19 |
|---|---|---|---|---|---|
| **5** |   |   |   |   | ✓ |
| **6** |   |   | ✓ |   | ✓ |
| **7** | ✓ |   |   | ✓ | ✓ |
| **8** | ✓ | ✓ | ✓ | ✓ |   |

A："我不知道 C 的生日，但我知道 B 也不知道。"
B："一开始我不知道，但现在我知道了。"
A："现在我也知道了。"
C 的生日是哪天？每一句话排除了哪些日期？

### 四、综合题：整除条件 + 隔板 + 补集（样卷 6 题型，新题）

**题 13** 从 1, 2, …, 30 中选 3 个不同的数（不计顺序），使它们的和能被 3 整除，有多少种选法？（提示：按除以 3 的余数把 30 个数分成三类。）

**题 14** 方程 x₁ + x₂ + x₃ + x₄ = 20 的正整数解中，有多少组满足 x₁x₂x₃x₄ 是偶数？（提示：先数补集"乘积是奇数"，即四个数都是奇数，令 xᵢ = 2yᵢ + 1。）

**题 15** 方程 x₁ + x₂ + x₃ = 13 的正整数解，要求 x₁x₂x₃ 是偶数。
(a) 有序解 (x₁, x₂, x₃) 有多少组？
(b) 不计顺序（允许有相同的数）有多少种？

**题 16** 方程 x₁ + x₂ + x₃ = 24 的正整数解中，有多少组满足 x₁x₂x₃ 能被 4 整除？（提示：乘积**不**能被 4 整除，要么三个都是奇数，要么恰好一个是偶数且它不是 4 的倍数。先想想哪种情况根本不可能。）

### 五、集合论证：取最小元（样卷 5 题型，新题）

**题 17** 设 S = {12x + 20y : x、y 是整数，且 12x + 20y > 0}，m 是 S 中最小的数。
(a) 写出 S 中的几个数，猜一猜 m 是多少。
(b) 证明：m 整除 S 中的每一个数。（提示：对 s ∈ S 做带余除法 s = qm + r，0 ≤ r < m，看 r 是什么形式。）
(c) 证明 m = 4。

**题 18** (a) 证明：任何有限的偏序集都至少有一个极小元。（提示：取"下面的元素最少"的那个元素 a，假设有 b < a，推出矛盾。）
(b) 由 (a) 说明：任何有限偏序集都有线性扩展。

### 六、复习：10-20 新错的题型

**题 19（清单 21）** 数线性扩展（每一步看当前有哪几个极小元，它们都可以先拿）：
(a) {a, b, c, d, e, f} 只有 a < b < c 和 d < e < f 这些关系；
(b) {a, b, c, d} 只有 a < c、b < c、b < d 这三条关系。

**题 20（清单 22）** 判断下面每个关系是偏序、全序、等价关系，还是都不是（可能不止一种）。先看清集合是什么。
(a) 正整数集上，a R b ⇔ a ≥ b；
(b) 班上所有同学的集合上，a R b ⇔ a 和 b 生日同一天；再说说它的等价类是什么；
(c) {1, 2, 3, 4} 的全部子集上，A R B ⇔ |A| ≤ |B|；
(d) 整数集上，a R b ⇔ |a − b| ≤ 1；
(e) {1, 2, 3, 4} 上，a R b ⇔ a = b。
