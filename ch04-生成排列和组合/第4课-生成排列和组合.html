1　生成全排列：可移动整数算法（幻灯片 171–175）

出发点：把 n 插进去

先看一个简单的观察：从 {1,…,n} 的一个排列里删掉 n，剩下的就是 {1,…,n−1} 的排列。反过来，把 n 插到 {1,…,n−1} 的每个排列的每个空位里，就能得到 {1,…,n} 的全部排列。

n=3 时，从 n=2 的两个排列 12、21 出发，让 3 从右往左、再从左往右地"扫"过去：

从 12 出发，3 从右往左走123 → 132 → 312
换成 21，3 从左往右走回来321 → 231 → 213

一共 6 个，相邻两个之间只交换了一对相邻的数。下面的算法就是把这种"来回扫"写成机械的规则。

可移动整数

给每个数头上加一个箭头（←或→）。如果一个数的箭头指向一个比它小的相邻数，它就是"可移动的"。

  • ←2 ←1：2 的箭头指向 1，1 比 2 小，所以 2 可移动。
  • ←1 ←2：1 的箭头指向外面，什么都没指，不可移动。
  • →3 ←4：3 的箭头指向 4，4 比 3 大，3 不可移动；4 指向 3，4 可移动。

所以 1 永远不可移动（没有比它小的数）；n 只要箭头不指向边界外，就总是可移动的。

算法（Johnson–Trotter）：从 ←1 ←2 … ←n 开始，只要还有可移动的数，就重复：

  1. 找出最大的可移动整数 m；
  2. 把 m 和它箭头指向的相邻数交换（箭头跟着数走）；
  3. 把所有比 m 大的数的箭头反向。

没有可移动的数时停止，这时 n! 个排列刚好全部列完。

为什么要引入可移动数？它和"把 n 插进去"是什么关系

问题出在"插进去"要先有整张表。上面 n=3 的做法，得先把 n=2 的全部排列（12、21）列好，3 才能在它们上面来回扫；而 n=2 的表又要从 n=1 的表来。这是一层套一层的递归。我们想要的是：手上只有当前这一个排列，就能直接算出下一个。

只看 312 这一行，你说不出下一步该干什么：3 是正在往左走，还是刚走完要回头？谁该动？缺的信息有两样，可移动数的概念正好把它们补上：

  1. 箭头 = 这个数正在往哪个方向扫。"插进去"的图里，3 先从右往左扫、再从左往右扫，箭头就是把这个方向记在数头上。
  2. 可移动 = 这一趟还没扫完，还能再走一步。数 k 只负责在比它小的数（1…k−1 的排列）中间穿行。箭头指着比它小的数，说明前面还有空位可以走。箭头指到边界外，说明这一趟走到头了。箭头指着比它大的数，那一步不归它管：k 和更大的数交换位置，属于那个更大的数自己的扫动。

有了这两个概念，算法的三条规则就是"插进去"的白话翻译：

  • 选最大的可移动数：n 最优先，只要 n 还没扫到头，就一直是 n 在走。这就是"n 扫过一个排列"。
  • n 扫到头、不可移动了，才轮到比它小的数动一步。忽略 n 看，这一步正好把 n−1 个数的排列换成表里的下一个，也就是"换下一个排列给 n 扫"。
  • 把比 m 大的数的箭头反向：下面的排列换了，n 掉头往回扫。

拿 n=3 一步步对照（括号里是忽略 3 之后的样子）：

  1. ←1 ←2 ←3 即 123：最大可移动是 3，往左走 → 132 → 312。这是 3 在（12）上从右往左扫。
  2. 312：3 的箭头指向边界外，不可移动了。下一个最大可移动是 2（它指着 1），2 和 1 交换 → 321。忽略 3，（12）变成了（21）：换下一个排列。
  3. 2 动了，比 2 大的 3 箭头反向变成 →。3 往右扫：231 → 213。这是 3 在（21）上从左往右扫回来。
  4. 213：3 到了右边界，2 的箭头指向左边界外，1 永远不动。没有可移动数，停止。6 个排列和上面"插进去"的表完全一样。

一句话："把 n 插进去"说的是这些排列长什么样，"可移动数"是让你不用存整张表、只看当前一行就能接着往下走的记号。n=4 时，3 和 2 也在用同样的规则，在更小的那层里来回扫。

2　逆序与逆序列（幻灯片 176–184）

逆序

在排列里，前面的数比后面的数大，这一对就叫一个逆序。例如排列 31524：

  • 3 在 1 前面且 3 > 1：逆序 (3,1)
  • 3 在 2 前面且 3 > 2：逆序 (3,2)
  • 5 在 2 前面：(5,2)；5 在 4 前面：(5,4)

一共 4 个逆序。只有 12…n 一个逆序都没有。逆序个数是奇数的叫奇排列，偶数的叫偶排列（行列式的正负号就是这么定的，幻灯片 183）。

逆序列 a₁, a₂, …, aₙ

aⱼ = 排在 j 前面、而且比 j 大的数有几个。它衡量 j "被挤到后面多远"。还是 31524：

jj 前面的数其中比 j 大的aⱼ
1331
23, 1, 53, 52
3（没有）—0
43, 1, 5, 251
53, 1—0

所以 31524 的逆序列是 1, 2, 0, 1, 0，加起来 4，正好是逆序总数。

自己试：输入一个排列，算逆序列

逆序列的范围，以及为什么能反推回排列

比 j 大的数只有 n−j 个，所以 0 ≤ aⱼ ≤ n−j：a₁ 在 0…n−1 之间，a₂ 在 0…n−2 之间，……，aₙ 一定是 0。满足这些范围的序列一共有 n×(n−1)×…×1 = n! 个，正好和排列一样多。

这个数是用乘法原理数出来的：a₁ 有 n 种取法（0…n−1），a₂ 有 n−1 种（0…n−2），……，aₙ 只有 1 种（只能是 0）。每个位置的取值范围只看 j，不受前面填了什么影响，所以可以直接相乘。n=3 时 a₁∈{0,1,2}、a₂∈{0,1}、a₃=0，全部列出来是 000、010、100、110、200、210，共 3×2×1 = 6 个。

注意谁会重复：排列 1…n 里每个数恰好出现一次，不会重复；但逆序列可以有重复的值，比如 31524 的逆序列是 1,2,0,1,0。它只受 0 ≤ aⱼ ≤ n−j 限制。（"序列"本身只是一串有顺序的数，允许重复；有重复元素的排列是第3课的多重集排列。）

定理：每个满足上面范围的序列 b₁,…,bₙ，都恰好是一个排列的逆序列。所以排列和逆序列一一对应。

怎么从逆序列造出排列？讲义给了两种算法。算法 II（填空位）最直观：

  1. 先摆 n 个空位。
  2. 放 1：前面要有 b₁ 个比它大的数，而所有别的数都比 1 大，所以 1 放在第 b₁+1 个空位。
  3. 放 2：前面要有 b₂ 个比 2 大的数。这些数还没放，必须给它们留出 b₂ 个空位，所以 2 放在从左数第 b₂+1 个空位。
  4. 依此类推：放 k 时，数剩下的空位，放在第 bₖ+1 个。
演示：由逆序列 5,3,4,0,2,1,1,0 造排列（讲义第 181 页例题）

讲义里的算法 I 是反过来做：先写 8，再按 b₇ 把 7 插到 8 的前或后，再按 b₆ 插 6……插 k 时，它前面要有 bₖ 个已经写好的数（这些都比 k 大）。两种算法得到同一个排列 48625137。

造出来的排列是唯一的吗？是的，因为每一步都没得选。放 j 的时候，比 j 小的数已经放好，剩下的空位以后全部由比 j 大的数来填。所以"j 前面有几个比它大的数"就等于"j 前面留着几个空位"：bⱼ = 2 就只能放第 3 个空位，放第 2 个或第 4 个，逆序数就变成 1 或 3。另外它也总放得下：放 j 时还剩 n−j+1 个空位，而 bⱼ ≤ n−j，第 bⱼ+1 个空位一定存在。

  1. 例：b = 1,2,0,1,0（n=5）。放 1：第 2 个空 → _ 1 _ _ _
  2. 放 2：空位是 1、3、4、5 号，第 3 个空是 4 号 → _ 1 _ 2 _
  3. 放 3：第 1 个空 → 3 1 _ 2 _
  4. 放 4：空位是 3、5 号，第 2 个空是 5 号 → 3 1 _ 2 4
  5. 放 5：只剩 3 号 → 3 1 5 2 4，只有这一个答案。

不用这个算法，结论也成立。上面的推理对任何一个逆序列是 b 的排列 π 都适用，不依赖构造方法：其他数都比 1 大，所以 1 在 π 里前面恰好有 b₁ 个数，位置被定死；除了 1 其他数都比 2 大，所以不算 1 那格，2 前面恰好有 b₂ 个数，位置也被定死；依此类推。所以两个逆序列相同的排列，每个数的位置都一样，就是同一个排列。

也可以用鸽巢原理看：排列有 n! 个，合法逆序列也有 n! 个，每个逆序列都至少对应一个排列（算法造得出来）。如果某个逆序列对应两个排列，n! 个排列只能分到少于 n! 个逆序列上，必有别的逆序列一个排列都没有，矛盾。

"总能造出来"加上"只造得出一个"，就是上面定理说的排列和逆序列一一对应。

用相邻交换排好序

每交换一对相邻的、顺序颠倒的数，逆序个数恰好减 1。所以把排列变成 12…n 最少要交换的次数 = 逆序个数。讲义第 184 页把 361245 变成 123456，用了 6 次，因为 361245 有 6 个逆序：(3,1)(3,2)(6,1)(6,2)(6,4)(6,5)。

361245 → 316245 → 136245 → 132645 → 123645 → 123465 → 123456

为什么交换不会引入新的逆序，也不会一次去掉好几个？因为相邻交换只改变被交换的那两个数之间的先后。以 361245 → 316245 为例：

  1. 3 原来在 6、1 的前面，交换后还在它俩前面；2、4、5 原来在后面，交换后还在后面。
  2. 所以任何别的数和 6、和 1 的相对顺序都没变，唯一变了的是 (6,1) 这一对。
  3. 换的是"左大右小"的相邻对，逆序数恰好减 1；换"左小右大"的则加 1，所以只挑顺序颠倒的相邻对来换。
  4. 每次最多减 1，所以至少要换"逆序个数"次；而只要还没排好，就一定有一对左大右小的相邻数（否则整串已经是 12…n），所以正好这么多次就够。

不相邻的交换才可能一次去掉多个逆序：321 直接交换 3 和 1 得到 123，一下去掉 3 个，因为夹在中间的 2 和两边的相对顺序都变了。

3　生成全部子集：二进制加 1（幻灯片 185–189）

集合 S = {xn−1, …, x₁, x₀}。每个子集对应一个由 0 和 1 组成的 n 元组 an−1…a₁a₀：aᵢ = 1 表示 xᵢ 在子集里，0 表示不在。

  • S = {x₆,…,x₀} 时，子集 {x₅, x₄, x₂, x₀} 对应 0110101。
  • 反过来，1010001 对应 {x₆, x₄, x₀}。

把 n 元组看成二进制数，从 0 一直加 1 加到 2ⁿ−1，就按顺序列出了全部 2ⁿ 个子集。所以"第 k 个子集"就是 k 的二进制（从第 0 个开始数）。例如 7 元集合的第 108 个子集：108 = 1101100₂，对应 {x₆, x₅, x₃, x₂}。

加 1 的规则：从右往左找第一个 0，把它变成 1，它右边的 1 全部变成 0。

例：1010111 最右边的 0 在 a₃，变成 1011000。对应子集从 {x₆,x₄,x₂,x₁,x₀} 变成 {x₆,x₄,x₃}。

4　反射 Gray 码（幻灯片 190–197）

二进制顺序有个缺点：0111 → 1000 一下子改了 4 位。能不能排一个顺序，让相邻两个子集只差一个元素（n 元组只改 1 位）？可以，这就是 Gray 码。在 n 维立方体上看，它是沿着棱走、每个顶点恰好经过一次的路线。

构造：复制、倒过来、加前缀

从 n−1 阶造 n 阶：先把 n−1 阶按原顺序抄一遍，每个前面加 0；再把它倒过来抄一遍，每个前面加 1。

为什么接缝处也只差 1 位？上半段最后一个是 0 10，下半段第一个是 1 10，后面两位相同（倒过来抄，接缝两边是同一行），只有前缀变了。

不用构造整张表，直接求下一个

规则（幻灯片 194）：数一数当前 n 元组里有几个 1。

  1. 1 的个数是偶数：改最右边一位 a₀。
  2. 1 的个数是奇数：找到最右边的 1，改它左边紧挨着的那一位。

到 10…0 时结束。

讲义第 197 页的例子：10100110 有 4 个 1（偶数），改最后一位得 10100111；00011111 有 5 个 1（奇数），最右边的 1 在最后一位，改倒数第二位得 00011101。

演示：同一个 4 元集合，两种顺序对比

黄色格子是这一步改动的位。切到"二进制加 1"多点几下，到 0111 → 1000 那一步会看到 4 格同时变黄；Gray 码每一步只有 1 格。

5　字典序生成 r-组合（幻灯片 198–206）

为什么要单独生成 r-组合

到这里我们已经能列出全部排列（第1节）和全部子集（第3、4节）。但很多时候只要固定大小的子集：比如从 6 个人里选 4 个组队，要把 C(6,4) = 15 种选法一个不漏、一个不重地列出来。

最笨的办法是跑第3节的二进制方法，列出全部 2ⁿ 个子集，再只留下恰好有 r 个元素的那些。讲义第 198 页就是这么做的：从 {1,2,3,4} 的 16 个子集里挑出 2 元子集，得到

{1,2}, {1,3}, {2,3}, {1,4}, {2,4}, {3,4}

这有两个毛病：

  1. 浪费：n=20、r=3 时只要 C(20,3) = 1140 个，却要先走完 2²⁰ = 1048576 个子集。
  2. 顺序别扭：上面这串是按"最大的元素"先排的（含 4 的全在最后），不像人习惯的顺序。

所以我们换个思路：先给 r-组合定一个自然的顺序，再找一个规则，从当前这个组合直接跳到下一个，不碰其他大小的子集。这个顺序就是字典序。

字典序：把组合当成单词查字典

把每个组合的元素从小到大写成一个"单词"，例如 {2,3,4,7,8} 写成 23478，然后像查字典一样排序：从第一位开始比，第一个不同的位置上谁小谁在前。23478 和 23567 前两位相同，第三位 4 < 5，所以 23478 在前。（讲义第 199 页用集合的说法讲同一件事：只在 A、B 其中一个里出现的元素中，最小的那个属于谁，谁就在前。这里是 4，属于 A。）

还是 {1,2,3,4} 的 2-组合，按字典序排就是

12, 13, 14, 23, 24, 34

以 1 开头的全在前面，然后是以 2 开头的，和查字典一模一样。注意 14 的下一个是 23：第二位已经是最大的 4，加不动了，只好让第一位从 1 变 2，第二位重新从最小的 3 开始。下面的规则就是把这个"加不动就往左进一位"的动作说清楚。

一般地，{1,…,n} 的 r-组合里，第一个是 12…r，最后一个是 (n−r+1)…n。

求下一个：

  1. 从右往左找第一个还能变大的位置 k：aₖ+1 ≤ n，而且 aₖ+1 不在当前组合里。
  2. 把 aₖ 加 1，它后面各位依次填 aₖ+2, aₖ+3, …（能填多小就填多小）。前面各位不动。

讲义第 201 页的例子：{1,…,9} 的 5-组合，12389 的下一个是什么？

  • 最后一位 9 已经是 n，不能加；倒数第二位 8 加 1 是 9，但 9 已经在组合里，也不能加。
  • 第三位 3 加 1 是 4，不在组合里，可以。所以 k=3。
  • 3 变成 4，后面填 5、6：答案 12456。

为什么这样得到的就是紧挨着的下一个：要比当前大、又要尽量小，就得①改动的位置尽量靠右（和当前共用的开头尽量长），②那一位只加 1，③后面各位填能填的最小值。讲义第 201 页的说法是：以 123 开头的组合里 12389 已经是最后一个，所以下一个的开头只能是 12 加上比 3 大的数，其中最小的是 12456。

演示：{1,…,6} 的 4-组合（讲义第 204 页）

某个组合排第几

问题：{1,…,6} 的 4-组合按字典序排，1356 排第几？先把全部 15 个列出来看答案：

1234, 1235, 1236, 1245, 1246, 1256, 1345, 1346, 1356, 1456, 2345, 2346, 2356, 2456, 3456

它排第 9。我们想要一个不用全列出来也能算出来的办法。思路是：数出排在 1356 后面的有几个，再用总数 C(6,4) = 15 去减。

第 1 步：谁排在 1356 后面？按字典序，一个组合排在 1356 后面，意思是：从左往右比，第一个不一样的位置上，它的数更大。按"第一个不一样的位置在第几位"分成 4 类，每个排在后面的组合恰好属于其中一类：

  1. 第 1 位就不一样，而且更大：第一位 ≥ 2。
  2. 第 1 位相同（是 1），第 2 位更大：第二位 ≥ 4。
  3. 前 2 位相同（是 13），第 3 位更大：第三位 ≥ 6。
  4. 前 3 位相同（是 135），第 4 位更大：第四位 ≥ 7。

第 2 步：每一类各有几个？关键是组合要从小到大写，所以一旦某一位 ≥ k，它后面的位只会更大。于是"从这一位往后的所有数"都得从 {k,…,6} 里选。

  1. 第一位 ≥ 2：4 个数全部从 {2,3,4,5,6} 里选。反过来，从这 5 个里随便选 4 个，从小到大一写，第一位自然 ≥ 2。所以是 C(5,4) = 5 个：2345, 2346, 2356, 2456, 3456。
  2. 第一位是 1、第二位 ≥ 4：剩下 3 个数（第 2、3、4 位）都从 {4,5,6} 里选，C(3,3) = 1 个：1456。
  3. 前两位是 13、第三位 ≥ 6：剩下 2 个数从 {6} 里选，只有 1 个数却要选 2 个，C(1,2) = 0 个。
  4. 前三位是 135、第四位 ≥ 7：根本没有比 6 大的数，C(0,1) = 0 个。

排在后面的共 6 个，所以 1356 排第 15 − 6 = 9 位。可以在上面的演示里点到第 9 个核对一下。一般公式（幻灯片 205）：

位置 = C(n,r) − C(n−a₁, r) − C(n−a₂, r−1) − … − C(n−aᵣ, 1)

公式里每一项就是上面的一类：第 i 位比 aᵢ 大时，第 i 位到第 r 位这 r−i+1 个数都要从 {aᵢ+1,…,n} 这 n−aᵢ 个数里选，所以是 C(n−aᵢ, r−i+1)。

为什么不直接数前面的？也可以，但麻烦。排在前面的，某一位要比 aᵢ 小、又要比前一位大，得把每个可能的值分开算再加起来。数后面的，每一位只要一个组合数就够了。

6　偏序与等价关系（幻灯片 207–218）

关系和五个性质

集合 X 上的一个关系 R，就是规定哪些有序对 (a,b) "有关系"，记作 aRb。比如"整除"：2|6 成立，3|5 不成立。关系可能有以下性质（下面都用具体的关系举例）：

  • 自反：每个 x 都有 xRx。≤ 是（3 ≤ 3），< 不是。
  • 反自反：每个 x 都没有 xRx。< 是，⊂（真包含）是。
  • 对称：xRy 就一定 yRx。"同奇偶"是；≤ 不是（2 ≤ 5 但 5 ≤ 2 不成立）。
  • 反对称：xRy 和 yRx 同时成立，就一定 x = y。≤ 是；整除在正整数上也是（a|b 且 b|a 推出 a=b）。
  • 传递：xRy、yRz 就一定 xRz。≤、⊆、整除都是。

先从穿衣服说起：什么叫"偏"序

早上穿衣服有些先后是必须的：内裤在裤子前，裤子在鞋前，袜子在鞋前，衬衫在外套前。但也有很多对无所谓先后：袜子和衬衫谁先穿都行，内裤和外套也没有要求。

把"x 必须不晚于 y 穿"记作 x ≤ y，这就是一个偏序：它只规定了一部分元素之间的先后，另一部分元素之间"比不了"（叫不可比）。"偏"就是"局部、不完全"的意思。

反过来，如果任意两个元素都分得出先后，就叫全序（也叫线序）。比如按身高给全班排队（假设没有一样高的），任意两人都比得出谁矮；数的 ≤ 也是全序，任给两个数总有一个 ≤ 另一个。

看图分辨：全序的 Hasse 图（下面会讲怎么画）一定是一条竖直的链；只要图里有分叉，就有比不了的两个元素，是偏序但不是全序。

数学上要求偏序满足三条，用穿衣服来看都很自然：

  1. 自反 x ≤ x：一件衣服当然"不晚于"它自己。这条是技术性的，为了让 ≤ 包含"等于"。
  2. 反对称：x ≤ y 且 y ≤ x，就只能是同一件。也就是不能绕圈：不可能"袜子必须在鞋前，鞋又必须在袜子前"，否则根本穿不了。
  3. 传递：内裤 ≤ 裤子、裤子 ≤ 鞋，就推出内裤 ≤ 鞋。先后要求会顺着传下去。

全序 = 偏序 + 一条额外要求：任意两个 x、y，x ≤ y 和 y ≤ x 至少有一个成立。

偏序：自反 + 反对称 + 传递

⊆、≤、整除 | 都是偏序。之所以叫"偏"，是因为有些元素之间比不了大小：{1} 和 {2} 谁也不包含谁，2 和 3 谁也不整除谁。如果任意两个都能比（比如 ≤），就叫全序（线序）。n 个元素上的全序，和 n 个元素的排列一一对应，所以有 n! 个。

如果 a < b 而且中间再也夹不进别的元素，就说 b 覆盖 a。只画覆盖关系、让大的在上面，得到的图叫 Hasse 图：

读图方法：沿着线一直往上走能到达，就表示"小于等于"。比如右图 2 → 4 → 8，所以 2|8；3 和 4 之间没有往上的路，所以它们不可比。

判断练习：

  • 数的 ≤：任意两个数都能比，全序。
  • {1,2,3} 的子集按 ⊆：{1} 和 {2} 谁也不包含谁，偏序，不是全序。（但 {1} 和 {1,2} 是可比的，偏序不是"都不能比"，而是"不保证都能比"。）
  • 1 到 8 按整除：2 和 3 谁也不整除谁，偏序，不是全序。
  • 只看 {1,2,4,8} 按整除：任意两个都是小的整除大的，全序。同一个关系，换个集合结论就可能变。

线性扩张：把偏序"排成一排"

能不能把一个偏序集的元素排成一行，使得原来 a ≤ b 的，排完 a 仍在 b 前面？可以，方法是反复拿走一个最小元（下面没有比它小的元素）：

  • 左图：先拿 ∅，再拿三个单元素集，再拿三个两元素集，最后拿 {1,2,3}：∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}。
  • 右图：1, 2, …, 8 本身就是一个线性扩张，因为 i | j 时一定有 i ≤ j。

回到穿衣服：线性扩张就是你实际穿衣服的那一个顺序，比如 衬衫、内裤、袜子、裤子、外套、鞋。原来比不了的（袜子和衬衫）你随便定了个先后，原来必须的先后一条都没违反。所以线性扩张就是"把偏序补成全序"。

等价关系：自反 + 对称 + 传递

和偏序只差一个字：偏序要反对称，等价关系要对称。例子："除以 3 余数相同"。和 a 等价的全体元素叫 a 的等价类 [a]。在 {1,…,9} 上：

[3] = {3, 6, 9}[1] = {1, 4, 7}[2] = {2, 5, 8}

定理（幻灯片 218）：等价类把 X 分成互不相交的非空部分；反过来，X 的任意一种划分，都对应一个等价关系（"在同一块里"）。所以等价关系 ⇔ 划分。

三者对照：偏序、全序、等价关系怎么分

三个名字听着像三种东西，其实是同一个问题的三种答案：这个关系满足了哪几条性质。先记住这张表：

性质意思偏序全序等价
自反每个 x 都有 xRx✓✓✓
传递xRy 且 yRz ⇒ xRz✓✓✓
反对称xRy 且 yRx ⇒ x = y（两个不同元素不能互相有关系）✓✓—
对称xRy ⇒ yRx（有关系就一定是双向的）——✓
任意两个可比任意 x、y，xRy 或 yRx 至少一个成立不要求✓—
  • 偏序和等价都要自反、传递，只差一个字：偏序要反对称，等价要对称。
  • 全序不是第三种独立的东西，它是额外满足"任意两个都能比"的偏序。全序一定是偏序，偏序不一定是全序。
  • 一句话区分：偏序讲上下（图会分叉），全序是上下排成一列（图是一根竖线），等价讲分组（画成几块，块内两两双向相关，块间都不相关）。

最容易混的两处

对称 vs 反对称

对称：aRb ⇒ bRa
反对称：aRb 且 bRa ⇒ a = b

对称说"能过去就一定能回来"；反对称说"两个不同的元素不能互相过去又回来"。

例："a − b 是偶数"。2 − 4 = −2 是偶数，所以 2R4；4 − 2 = 2 也是偶数，所以 4R2；但 2 ≠ 4，反对称不成立，不是偏序。它是对称的（再加自反、传递），所以是等价关系，两个等价类：偶数、奇数。

< 和 ≤

≤：自反 ✓ 反对称 ✓ 传递 ✓
<：自反 ✗（1 < 1 不成立）

偏序第一条就要自反，所以 < 不是偏序，更不是全序。全序指的是 ≤。

< 叫"严格偏序"，就是 ≤ 去掉所有 (x, x)。讲"覆盖""比不了"时用 < 方便，但判断题问"是不是偏序"时，< 要判"不是"。

对称和反对称不是互相否定：一个关系可以两个都不满足，也可以两个都满足（只有"a = b"这种，它同时是偏序和等价关系）。

考试时的判断顺序

  1. 自反：每个 x 都有 xRx 吗？不满足就直接"都不是"，写反例（如 1R1 不成立）。
  2. 传递：xRy、yRz 能推出 xRz 吗？不满足也是"都不是"，写出具体的 x、y、z。
  3. 看方向：有没有两个不同元素 aRb 且 bRa？没有（反对称）→ 偏序，再看第 4 步；有关系就总是双向（对称）→ 等价关系，写出等价类。
  4. 偏序再问任意两个都能比吗：能 → 全序；找到一对比不了的（如 2 和 3 互不整除）→ 只是偏序。

判"不是"时一定给一个具体反例，这是拿分的地方。
