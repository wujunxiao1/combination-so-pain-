1　生成全排列：可移动整数算法（幻灯片 171–175）

出发点：把 n 插进去

先看一个简单的观察：从 {1,…,n} 的一个排列里删掉 n，剩下的就是 {1,…,n−1} 的排列。反过来，把 n 插到 {1,…,n−1} 的每个排列的每个空位里，就能得到 {1,…,n} 的全部排列。

n=3 时，从 n=2 的两个排列 12、21 出发，让 3 从右往左、再从左往右地"扫"过去：

从 12 出发，3 从右往左走123 → 132 → 312
换成 21，3 从左往右走回来321 → 231 → 213

一共 6 个，相邻两个之间只交换了一对相邻的数。下面的算法就是把这种"来回扫"写成机械的规则。

可移动整数

给每个数头上加一个箭头（←或→）。如果一个数的箭头指向一个比它小的相邻数，它就是"可移动的"。

  • ←2 ←1：2 的箭头指向 1，1 比 2 小，所以 2 可移动。
  • ←1 ←2：1 的箭头指向外面，什么都没指，不可移动。
  • →3 ←4：3 的箭头指向 4，4 比 3 大，3 不可移动；4 指向 3，4 可移动。

所以 1 永远不可移动（没有比它小的数）；n 只要箭头不指向边界外，就总是可移动的。

算法（Johnson–Trotter）：从 ←1 ←2 … ←n 开始，只要还有可移动的数，就重复：

  1. 找出最大的可移动整数 m；
  2. 把 m 和它箭头指向的相邻数交换（箭头跟着数走）；
  3. 把所有比 m 大的数的箭头反向。

没有可移动的数时停止，这时 n! 个排列刚好全部列完。

为什么要引入可移动数？它和"把 n 插进去"是什么关系

问题出在"插进去"要先有整张表。上面 n=3 的做法，得先把 n=2 的全部排列（12、21）列好，3 才能在它们上面来回扫；而 n=2 的表又要从 n=1 的表来。这是一层套一层的递归。我们想要的是：手上只有当前这一个排列，就能直接算出下一个。

只看 312 这一行，你说不出下一步该干什么：3 是正在往左走，还是刚走完要回头？谁该动？缺的信息有两样，可移动数的概念正好把它们补上：

  1. 箭头 = 这个数正在往哪个方向扫。"插进去"的图里，3 先从右往左扫、再从左往右扫，箭头就是把这个方向记在数头上。
  2. 可移动 = 这一趟还没扫完，还能再走一步。数 k 只负责在比它小的数（1…k−1 的排列）中间穿行。箭头指着比它小的数，说明前面还有空位可以走。箭头指到边界外，说明这一趟走到头了。箭头指着比它大的数，那一步不归它管：k 和更大的数交换位置，属于那个更大的数自己的扫动。

有了这两个概念，算法的三条规则就是"插进去"的白话翻译：

  • 选最大的可移动数：n 最优先，只要 n 还没扫到头，就一直是 n 在走。这就是"n 扫过一个排列"。
  • n 扫到头、不可移动了，才轮到比它小的数动一步。忽略 n 看，这一步正好把 n−1 个数的排列换成表里的下一个，也就是"换下一个排列给 n 扫"。
  • 把比 m 大的数的箭头反向：下面的排列换了，n 掉头往回扫。

拿 n=3 一步步对照（括号里是忽略 3 之后的样子）：

  1. ←1 ←2 ←3 即 123：最大可移动是 3，往左走 → 132 → 312。这是 3 在（12）上从右往左扫。
  2. 312：3 的箭头指向边界外，不可移动了。下一个最大可移动是 2（它指着 1），2 和 1 交换 → 321。忽略 3，（12）变成了（21）：换下一个排列。
  3. 2 动了，比 2 大的 3 箭头反向变成 →。3 往右扫：231 → 213。这是 3 在（21）上从左往右扫回来。
  4. 213：3 到了右边界，2 的箭头指向左边界外，1 永远不动。没有可移动数，停止。6 个排列和上面"插进去"的表完全一样。

一句话："把 n 插进去"说的是这些排列长什么样，"可移动数"是让你不用存整张表、只看当前一行就能接着往下走的记号。n=4 时，3 和 2 也在用同样的规则，在更小的那层里来回扫。

2　逆序与逆序列（幻灯片 176–184）

逆序

在排列里，前面的数比后面的数大，这一对就叫一个逆序。例如排列 31524：

  • 3 在 1 前面且 3 > 1：逆序 (3,1)
  • 3 在 2 前面且 3 > 2：逆序 (3,2)
  • 5 在 2 前面：(5,2)；5 在 4 前面：(5,4)

一共 4 个逆序。只有 12…n 一个逆序都没有。逆序个数是奇数的叫奇排列，偶数的叫偶排列（行列式的正负号就是这么定的，幻灯片 183）。

逆序列 a₁, a₂, …, aₙ

aⱼ = 排在 j 前面、而且比 j 大的数有几个。它衡量 j "被挤到后面多远"。还是 31524：

jj 前面的数其中比 j 大的aⱼ
1331
23, 1, 53, 52
3（没有）—0
43, 1, 5, 251
53, 1—0

所以 31524 的逆序列是 1, 2, 0, 1, 0，加起来 4，正好是逆序总数。

逆序列的范围，以及为什么能反推回排列

比 j 大的数只有 n−j 个，所以 0 ≤ aⱼ ≤ n−j：a₁ 在 0…n−1 之间，a₂ 在 0…n−2 之间，……，aₙ 一定是 0。满足这些范围的序列一共有 n×(n−1)×…×1 = n! 个，正好和排列一样多。

这个数是用乘法原理数出来的：a₁ 有 n 种取法（0…n−1），a₂ 有 n−1 种（0…n−2），……，aₙ 只有 1 种（只能是 0）。每个位置的取值范围只看 j，不受前面填了什么影响，所以可以直接相乘。n=3 时 a₁∈{0,1,2}、a₂∈{0,1}、a₃=0，全部列出来是 000、010、100、110、200、210，共 3×2×1 = 6 个。

注意谁会重复：排列 1…n 里每个数恰好出现一次，不会重复；但逆序列可以有重复的值，比如 31524 的逆序列是 1,2,0,1,0。它只受 0 ≤ aⱼ ≤ n−j 限制。（"序列"本身只是一串有顺序的数，允许重复；有重复元素的排列是第3课的多重集排列。）

定理：每个满足上面范围的序列 b₁,…,bₙ，都恰好是一个排列的逆序列。所以排列和逆序列一一对应。

怎么从逆序列造出排列？讲义给了两种算法。算法 II（填空位）最直观：

  1. 先摆 n 个空位。
  2. 放 1：前面要有 b₁ 个比它大的数，而所有别的数都比 1 大，所以 1 放在第 b₁+1 个空位。
  3. 放 2：前面要有 b₂ 个比 2 大的数。这些数还没放，必须给它们留出 b₂ 个空位，所以 2 放在从左数第 b₂+1 个空位。
  4. 依此类推：放 k 时，数剩下的空位，放在第 bₖ+1 个。
演示：由逆序列 5,3,4,0,2,1,1,0 造排列（讲义第 181 页例题）

讲义里的算法 I 是反过来做：先写 8，再按 b₇ 把 7 插到 8 的前或后，再按 b₆ 插 6……插 k 时，它前面要有 bₖ 个已经写好的数（这些都比 k 大）。两种算法得到同一个排列 48625137。

用相邻交换排好序

每交换一对相邻的、顺序颠倒的数，逆序个数恰好减 1。所以把排列变成 12…n 最少要交换的次数 = 逆序个数。讲义第 184 页把 361245 变成 123456，用了 6 次，因为 361245 有 6 个逆序：(3,1)(3,2)(6,1)(6,2)(6,4)(6,5)。

3　生成全部子集：二进制加 1（幻灯片 185–189）

集合 S = {xn−1, …, x₁, x₀}。每个子集对应一个由 0 和 1 组成的 n 元组 an−1…a₁a₀：aᵢ = 1 表示 xᵢ 在子集里，0 表示不在。

  • S = {x₆,…,x₀} 时，子集 {x₅, x₄, x₂, x₀} 对应 0110101。
  • 反过来，1010001 对应 {x₆, x₄, x₀}。

把 n 元组看成二进制数，从 0 一直加 1 加到 2ⁿ−1，就按顺序列出了全部 2ⁿ 个子集。所以"第 k 个子集"就是 k 的二进制（从第 0 个开始数）。例如 7 元集合的第 108 个子集：108 = 1101100₂，对应 {x₆, x₅, x₃, x₂}。

加 1 的规则：从右往左找第一个 0，把它变成 1，它右边的 1 全部变成 0。

例：1010111 最右边的 0 在 a₃，变成 1011000。对应子集从 {x₆,x₄,x₂,x₁,x₀} 变成 {x₆,x₄,x₃}。

4　反射 Gray 码（幻灯片 190–197）

二进制顺序有个缺点：0111 → 1000 一下子改了 4 位。能不能排一个顺序，让相邻两个子集只差一个元素（n 元组只改 1 位）？可以，这就是 Gray 码。在 n 维立方体上看，它是沿着棱走、每个顶点恰好经过一次的路线。

构造：复制、倒过来、加前缀

从 n−1 阶造 n 阶：先把 n−1 阶按原顺序抄一遍，每个前面加 0；再把它倒过来抄一遍，每个前面加 1。

为什么接缝处也只差 1 位？上半段最后一个是 0 10，下半段第一个是 1 10，后面两位相同（倒过来抄，接缝两边是同一行），只有前缀变了。

不用构造整张表，直接求下一个

规则（幻灯片 194）：数一数当前 n 元组里有几个 1。

  1. 1 的个数是偶数：改最右边一位 a₀。
  2. 1 的个数是奇数：找到最右边的 1，改它左边紧挨着的那一位。

到 10…0 时结束。

讲义第 197 页的例子：10100110 有 4 个 1（偶数），改最后一位得 10100111；00011111 有 5 个 1（奇数），最右边的 1 在最后一位，改倒数第二位得 00011101。

5　字典序生成 r-组合（幻灯片 198–206）

只要大小为 r 的子集时，把每个组合的元素从小到大写成一个"单词"，例如 {2,3,4,7,8} 写成 23478，然后像查字典一样排序：从第一位开始比，第一个不同的位置上谁小谁在前。23478 和 23567 前两位相同，第三位 4 < 5，所以 23478 在前。

{1,…,n} 的 r-组合里，第一个是 12…r，最后一个是 (n−r+1)…n。

求下一个：

  1. 从右往左找第一个还能变大的位置 k：aₖ+1 ≤ n，而且 aₖ+1 不在当前组合里。
  2. 把 aₖ 加 1，它后面各位依次填 aₖ+2, aₖ+3, …（能填多小就填多小）。前面各位不动。

讲义第 201 页的例子：{1,…,9} 的 5-组合，12389 的下一个是什么？

  • 最后一位 9 已经是 n，不能加；倒数第二位 8 加 1 是 9，但 9 已经在组合里，也不能加。
  • 第三位 3 加 1 是 4，不在组合里，可以。所以 k=3。
  • 3 变成 4，后面填 5、6：答案 12456。
演示：{1,…,6} 的 4-组合（讲义第 204 页）

某个组合排第几

与其往前数，不如数排在它后面的有几个，再用总数减。以 {1,…,6} 的 4-组合 1356 为例（总数 C(6,4)=15）：

  • 第一位比 1 大的：从 {2,…,6} 这 5 个数里选 4 个，C(5,4) = 5 个。
  • 第一位是 1、第二位比 3 大的：从 {4,5,6} 选 3 个，C(3,3) = 1 个。
  • 前两位是 13、第三位比 5 大的：从 {6} 选 2 个，C(1,2) = 0 个。
  • 前三位是 135、第四位比 6 大的：C(0,1) = 0 个。

排在后面的共 6 个，所以 1356 排第 15 − 6 = 9 位。可以在上面的演示里点到第 9 个核对一下。一般公式（幻灯片 205）：

位置 = C(n,r) − C(n−a₁, r) − C(n−a₂, r−1) − … − C(n−aᵣ, 1)

6　偏序与等价关系（幻灯片 207–218）

关系和五个性质

集合 X 上的一个关系 R，就是规定哪些有序对 (a,b) "有关系"，记作 aRb。比如"整除"：2|6 成立，3|5 不成立。关系可能有以下性质（下面都用具体的关系举例）：

  • 自反：每个 x 都有 xRx。≤ 是（3 ≤ 3），< 不是。
  • 反自反：每个 x 都没有 xRx。< 是，⊂（真包含）是。
  • 对称：xRy 就一定 yRx。"同奇偶"是；≤ 不是（2 ≤ 5 但 5 ≤ 2 不成立）。
  • 反对称：xRy 和 yRx 同时成立，就一定 x = y。≤ 是；整除在正整数上也是（a|b 且 b|a 推出 a=b）。
  • 传递：xRy、yRz 就一定 xRz。≤、⊆、整除都是。

偏序：自反 + 反对称 + 传递

⊆、≤、整除 | 都是偏序。之所以叫"偏"，是因为有些元素之间比不了大小：{1} 和 {2} 谁也不包含谁，2 和 3 谁也不整除谁。如果任意两个都能比（比如 ≤），就叫全序（线序）。n 个元素上的全序，和 n 个元素的排列一一对应，所以有 n! 个。

如果 a < b 而且中间再也夹不进别的元素，就说 b 覆盖 a。只画覆盖关系、让大的在上面，得到的图叫 Hasse 图：

读图方法：沿着线一直往上走能到达，就表示"小于等于"。比如右图 2 → 4 → 8，所以 2|8；3 和 4 之间没有往上的路，所以它们不可比。

线性扩张：把偏序"排成一排"

能不能把一个偏序集的元素排成一行，使得原来 a ≤ b 的，排完 a 仍在 b 前面？可以，方法是反复拿走一个最小元（下面没有比它小的元素）：

  • 左图：先拿 ∅，再拿三个单元素集，再拿三个两元素集，最后拿 {1,2,3}：∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}。
  • 右图：1, 2, …, 8 本身就是一个线性扩张，因为 i | j 时一定有 i ≤ j。

等价关系：自反 + 对称 + 传递

和偏序只差一个字：偏序要反对称，等价关系要对称。例子："除以 3 余数相同"。和 a 等价的全体元素叫 a 的等价类 [a]。在 {1,…,9} 上：

[3] = {3, 6, 9}[1] = {1, 4, 7}[2] = {2, 5, 8}

定理（幻灯片 218）：等价类把 X 分成互不相交的非空部分；反过来，X 的任意一种划分，都对应一个等价关系（"在同一块里"）。所以等价关系 ⇔ 划分。

找出 →4 ←8 →3 ←1 →6 ←7 ←2 →5 中所有可移动的整数。

看答案

8、3、7。逐个看箭头指向的邻居：4→8（8 更大，不行）；8←4（4 更小，可以）；3→1（可以）；1←3（更大，不行）；6→7（不行）；7←6（可以）；2←7（不行）；5→（指向外面，不行）。
