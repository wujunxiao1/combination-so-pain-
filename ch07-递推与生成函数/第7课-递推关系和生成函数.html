第7课　递推关系和生成函数

第1课数 2×n 棋盘的铺法时，我们没有一个一个去数，而是发现 f(n) = f(n−1) + f(n−2)：大问题的答案可以用小问题的答案算出来。这种式子叫递推关系。这一课做两件事。第一，把递推关系"解开"，得到一个直接代 n 就能算的公式（特征方程、特解）。第二，引入生成函数：把整串数 h₀, h₁, h₂, … 写成 h₀ + h₁x + h₂x² + … 这样一个"多项式"，让多项式乘法替我们计数，也用它来解递推。最后是指数生成函数，专门用来数"有顺序"的排列。每个方法都先用一个小数字说明为什么需要它，再给一般规则；三个演示可以一项一项地对账。

1　数列和递推关系（幻灯片 289–298）

为什么要谈"数列"

计数问题的答案往往跟一个参数 n 有关：棋盘有多长、有几个盘子、有几种水果。所以答案不是一个数，而是"每个 n 一个数"。比如第1课 2×n 棋盘的铺法数，n = 0, 1, 2, 3, 4, 5 时是 1, 1, 2, 3, 5, 8。把它们按 n 排成一串，就是一个数列：

h₀, h₁, h₂, …, hₙ, …　　（7.1）

hₙ 叫通项（第 n 项）。下标从 0 开始，是因为 n = 0 的情形（空棋盘、零个盘子）通常也有意义。

两种最熟悉的数列（幻灯片 289–291）

先看例子：1, 3, 5, 7, … 每一项比前一项多 2；1, 2, 4, 8, … 每一项是前一项的 2 倍。

  1. 等差数列：每项比前一项多一个固定的数 q。例：正奇数 1, 3, 5, …（h₀ = 1，q = 2）；常数列 4, 4, 4, …（h₀ = 4，q = 0）；0, 1, 2, …（h₀ = 0，q = 1）。通项 hₙ = h₀ + nq，因为从 h₀ 走到 hₙ 加了 n 次 q。
  2. 等比数列：每项是前一项的固定倍数 q。例：2 的幂 1, 2, 4, …（h₀ = 1，q = 2）。通项 hₙ = qⁿh₀，因为乘了 n 次 q。

讲义还举了一个计数出来的等比数列（幻灯片 291）：多重集 {4·a₀, 2·a₁, 2·a₂, …, 2·aₙ}（a₀ 有 4 个，后面 n 种各 2 个）有多少个子多重集？a₀ 可以取 0 到 4 个，5 种选法；其余每种取 0、1、2 个，各 3 种。乘法原理：hₙ = 5·3ⁿ。n = 1 时是 {4·a, 2·b}，5 × 3 = 15 个。为什么是等比：n 加 1 就是多一种可以取 0、1、2 个的东西，选法多乘一个 3。

等差：h₀, h₀+q, h₀+2q, …, h₀+nq, …　（7.2）

等比：h₀, qh₀, q²h₀, …, qⁿh₀, …　（7.3）

两种数列都由首项 h₀ 和 q 完全确定。

部分和（幻灯片 292–293）

常常要的不是第 n 项，而是前面所有项的总和。例：1 + 3 + 5 + 7 = 16。把 h₀ 到 hₙ 的和记作 sₙ，s₀, s₁, s₂, … 又是一个新数列，叫部分和。

等差：sₙ = (h₀) + (h₀+q) + … + (h₀+nq) = (n+1)h₀ + q·n(n+1)/2

等比：sₙ = h₀ + qh₀ + … + qⁿh₀ = h₀(qⁿ⁺¹ − 1)/(q − 1)（q ≠ 1）；q = 1 时 sₙ = (n+1)h₀

为什么：等差的和里 h₀ 出现 n+1 次，q 一共出现 0 + 1 + … + n = n(n+1)/2 次。核对：1 + 3 + 5 + 7 是 n = 3，4·1 + 2·3·4/2 = 4 + 12 = 16。等比的和：sₙ 乘 q 再减 sₙ，中间的项全部抵消，只剩 qⁿ⁺¹h₀ − h₀，所以 (q−1)sₙ = (qⁿ⁺¹−1)h₀。核对：1 + 2 + 4 + 8 = (2⁴ − 1)/(2 − 1) = 15。

递推关系：用前面的项算下一项（幻灯片 294）

等差数列可以写成 hₙ = hₙ₋₁ + q，等比数列可以写成 hₙ = q·hₙ₋₁：只要知道前一项，就能算出这一项。这种"用前面的项表示后面的项"的式子叫递推关系。上面两个是最简单的递推关系；下面这个稍复杂一点。

例：n 个圆把平面分成几块（幻灯片 294–295）

平面上画 n 个圆，要求两两相交（任意两个圆都交于两个不同的点，不能相离也不能相切），并且处于一般位置（没有三个圆过同一个点）。这 n 个圆把平面分成 hₙ 块，求 hₙ。

前几个：h₀ = 1，h₁ = 2，h₂ = 4，h₃ = 8。看起来像 2ⁿ，可是 h₄ = 14，不是 16。只看前几项去猜规律是靠不住的，要找到"为什么"。

加第 n 个圆时多出几块（n ≥ 2）：

  1. 新圆和原来 n−1 个圆每个都交于 2 点，而且这些点互不相同（一般位置），所以新圆上一共有 2(n−1) 个交点。
  2. 圆上有 m 个点（m ≥ 1）时，这些点把圆切成 m 段弧。所以新圆被切成 2(n−1) 段弧。
  3. 每一段弧都在原来的某一块里面穿过，把那一块一分为二。所以每段弧让块数多 1。

hₙ = hₙ₋₁ + 2(n−1)　（n ≥ 2）　（7.4）

核对：h₃ = h₂ + 4 = 8，h₄ = h₃ + 6 = 14。为什么要 n ≥ 2：n = 1 时新圆上没有交点，第 2 步"m 个点切成 m 段"不成立（一个点都没有的圆是一整圈，它把平面分成里外两块，多了 1 块而不是 0 块）。

把递推一层层展开就得到公式：hₙ = h₁ + 2·1 + 2·2 + … + 2(n−1) = 2 + n(n−1)，即

hₙ = n² − n + 2　（n ≥ 1）

n = 1 时也对（1 − 1 + 2 = 2），但 n = 0 时给出 2，而 h₀ = 1，所以公式不包括 n = 0。

Fibonacci 的兔子（幻灯片 296–298）

问题：年初把一对刚出生的兔子（一公一母）放进围栏。从第二个月起，母兔每个月生一对兔子；每对新兔子也从它们的第二个月起每月生一对。一年后围栏里有几对兔子？

设 fₙ = 第 n 个月月初的兔子对数。先手算：

  1. 第 1 个月初：1 对（刚出生，这个月在长大）。f₁ = 1。
  2. 第 2 个月初：还是这 1 对（第 1 个月没生）。f₂ = 1。
  3. 第 2 个月里，这对生了一对。第 3 个月初：2 对。f₃ = 2。
  4. 第 3 个月里，新生的那对还在长大，只有原来那对生。第 4 个月初：2 + 1 = 3 对。

一般的理由：第 n 个月初的兔子分成两部分。一部分是第 n−1 个月初就在的（兔子不会死），有 fₙ₋₁ 对；另一部分是第 n−1 个月里新生的。谁会在第 n−1 个月里生？已经长了至少一个月的兔子，也就是第 n−2 个月初就在的那 fₙ₋₂ 对，每对生一对。所以 fₙ = fₙ₋₁ + fₙ₋₂。

月份 n12345678910111213
月初对数 fₙ1123581321345589144233

讲义没有写出最后的数。按"第 n 个月初有 fₙ 对"，一年过完就是第 13 个月初，有 f₁₃ = 233 对（第 12 个月初是 144 对）。

Fibonacci 数列（7.5）：f₀ = 0，f₁ = 1，fₙ = fₙ₋₁ + fₙ₋₂（n ≥ 2）

补一个 f₀ = 0，是为了让 f₂ = f₁ + f₀ = 1 也符合递推。前 16 项：

fₙ01123581321345589144233377610

两个小性质（幻灯片 298）

部分和：先算 n = 4：f₀ + f₁ + f₂ + f₃ + f₄ = 0 + 1 + 1 + 2 + 3 = 7，而 f₆ = 8，正好差 1。一般地

sₙ = f₀ + f₁ + … + fₙ = fₙ₊₂ − 1　（7.6）

为什么（归纳法）：n = 0 时 s₀ = 0 = f₂ − 1。若 sₙ₋₁ = fₙ₊₁ − 1，则 sₙ = sₙ₋₁ + fₙ = fₙ₊₁ + fₙ − 1 = fₙ₊₂ − 1，最后一步就是 Fibonacci 递推。

奇偶性：fₙ 是偶数当且仅当 n 是 3 的倍数。看奇偶：f₀, f₁, f₂, … 是 偶 奇 奇 偶 奇 奇 偶 奇 奇 …，三个一循环。为什么会循环：fₙ 的奇偶只由前两项的奇偶决定（奇 + 奇 = 偶，奇 + 偶 = 奇）。从 (偶, 奇) 出发，下一项是奇，得到 (奇, 奇)；再下一项是偶，得到 (奇, 偶)；再下一项是奇，又回到 (偶, 奇)。三步回到起点，以后就一直重复，偶数恰好出现在 n = 0, 3, 6, … 。

2　Fibonacci 数的公式，以及几个计数问题（幻灯片 299–308）

为什么想要一个公式

想知道 f₃₀，用递推得先把 f₂ 到 f₂₉ 全算一遍。能不能有一个公式，直接把 n = 30 代进去？

想法：等比数列 qⁿ 满足最简单的递推 hₙ = q·hₙ₋₁。那 Fibonacci 递推有没有等比形式的解？试 fₙ = qⁿ（q ≠ 0），代进 fₙ − fₙ₋₁ − fₙ₋₂ = 0（7.7）：

qⁿ − qⁿ⁻¹ − qⁿ⁻² = qⁿ⁻²(q² − q − 1) = 0

q ≠ 0，所以只要 q² = q + 1。先用数试试：q = 1 时左边 1、右边 2，小了；q = 2 时左边 4、右边 3，大了；所以有一个根在 1 和 2 之间。解二次方程：

q₁ = (1+√5)/2 ≈ 1.618（记作 φ），　q₂ = (1−√5)/2 ≈ −0.618（记作 ψ）

核对：φ² ≈ 2.618 = φ + 1。所以 φⁿ 和 ψⁿ 都满足 Fibonacci 递推。可是它们的初值不对：φ⁰ = 1、φ¹ ≈ 1.618，而我们要 f₀ = 0、f₁ = 1。

为什么可以把两个解"混合"（幻灯片 300）

先看整数的例子：aₙ = 0, 1, 1, 2, 3, 5, … 和 bₙ = 2, 1, 3, 4, 7, 11, … 都满足"每项等于前两项之和"。把它们相加：2, 2, 4, 6, 10, 16, …，还是满足（2 + 2 = 4，2 + 4 = 6，4 + 6 = 10）。乘一个常数也一样。

为什么：若 aₙ = aₙ₋₁ + aₙ₋₂，bₙ = bₙ₋₁ + bₙ₋₂，那么

c₁aₙ + c₂bₙ = c₁(aₙ₋₁ + aₙ₋₂) + c₂(bₙ₋₁ + bₙ₋₂) = (c₁aₙ₋₁ + c₂bₙ₋₁) + (c₁aₙ₋₂ + c₂bₙ₋₂)

这一步用到递推的两个特点：各项只是乘常数再相加（线性），而且没有多出来的常数项（齐次）。如果递推是 hₙ = hₙ₋₁ + hₙ₋₂ + 1，两个解相加后那个 1 会变成 2，就不行了。

所以对任意常数 c₁、c₂，

fₙ = c₁·φⁿ + c₂·ψⁿ　（7.8）

都满足递推。剩下的事是选 c₁、c₂ 让初值对上（幻灯片 301）：

  1. n = 0：c₁ + c₂ = 0，所以 c₂ = −c₁。
  2. n = 1：c₁φ + c₂ψ = c₁(φ − ψ) = c₁·√5 = 1（φ − ψ = √5），所以 c₁ = 1/√5，c₂ = −1/√5。

为什么初值对上就够了：递推加上 f₀、f₁ 就把后面每一项都定死了。我们的公式满足同一个递推，又有同样的 f₀、f₁，所以每一项都一样。

定理（7.9，幻灯片 302）：fₙ = (1/√5)·((1+√5)/2)ⁿ − (1/√5)·((1−√5)/2)ⁿ　（n ≥ 0）

核对 n = 2：(φ² − ψ²)/√5 = (φ − ψ)(φ + ψ)/√5 = √5 · 1/√5 = 1。核对 n = 10：φ¹⁰/√5 ≈ 55.0036，ψ¹⁰/√5 ≈ 0.0036，相减正好 55。式子里全是无理数，结果却总是整数，因为 √5 的部分正好抵消。又因为 |ψ| < 1，ψⁿ/√5 很小，所以 fₙ 就是离 φⁿ/√5 最近的整数（这是习题 #305）。第3节的演示可以一项一项地对这个公式。

换一组初值（幻灯片 302–303）

同样的递推 gₙ = gₙ₋₁ + gₙ₋₂，但初值 g₀ = 2，g₁ = −1。前几项：2, −1, 1, 0, 1, 1, 2, 3, 5, 8, …（从 g₃ 开始又是 Fibonacci 数）。

φ、ψ 不变（它们只由递推决定），只有 c₁、c₂ 要重新算：

  1. n = 0：c₁ + c₂ = 2。
  2. n = 1：c₁φ + c₂ψ = −1。
  3. 第 2 式减去第 1 式的 ψ 倍：c₁(φ − ψ) = −1 − 2ψ = −1 − (1 − √5) = √5 − 2，所以 c₁ = (√5 − 2)/√5 ≈ 0.1056。
  4. c₂ = 2 − c₁ = (√5 + 2)/√5 ≈ 1.8944。

gₙ = ((√5−2)/√5)·φⁿ + ((√5+2)/√5)·ψⁿ

核对 n = 2：0.2764 + 0.7236 = 1 = g₂。注意：幻灯片 303 把 c₂ 也印成了 (√5−2)/√5，第一个方程印成了 "c₁ + c₁ = 2"，都是笔误。若 c₂ 也是 (√5−2)/√5，c₁ + c₂ ≈ 0.21，不等于 2。

铺砖问题又是 Fibonacci（幻灯片 303–305）

2×n 棋盘用多米诺骨牌铺满：第1课已经推过，hₙ = hₙ₋₁ + hₙ₋₂（看左上角那块骨牌是竖放还是横放）。讲义规定 h₀ = 1：2×0 的棋盘是空的，"什么都不放"就是它唯一的完美覆盖。这样规定是为了让 h₂ = h₁ + h₀ = 1 + 1 = 2 也符合递推。数列 1, 1, 2, 3, 5, … 正是 f₁, f₂, f₃, …，所以 hₙ = fₙ₊₁，用上面的公式就有通项。

1×n 棋盘用单格骨牌（1×1）和多米诺骨牌（1×2）铺满，方法数记作 bₙ。n = 3 时有 3 种：1+1+1、1+2、2+1。讲义的论证：

  1. 2×n 的铺法只看第一行，就得到 1×n 的一种铺法。
  2. 反过来，1×n 的每种铺法可以唯一地"补"成 2×n 的铺法：单格的位置放一块竖骨牌；1×2 的位置在它下面再放一块横骨牌。为什么第一行能看出全部：第1课推递推时见过，上面横放一块，它下面那两格只能也横放一块，所以横骨牌总是上下成对，第二行完全由第一行决定。
  3. 所以两边一一对应，bₙ = hₙ，也是 Fibonacci 数（去掉 f₀）。

也可以直接推：看最后一块是单格（剩下 1×(n−1)）还是 1×2（剩下 1×(n−2)），bₙ = bₙ₋₁ + bₙ₋₂。

Pascal 三角形的斜线和（幻灯片 306–308）

先算两个：

C(4,0) + C(3,1) + C(2,2) = 1 + 3 + 1 = 5 = f₅
C(5,0) + C(4,1) + C(3,2) = 1 + 4 + 3 = 8 = f₆

在 Pascal 三角形里，这些数排在一条从左下往右上的斜线上（第5课的三角形，从第 n−1 行最左边开始，每次上一行、右移一格）。

定理（幻灯片 306）：fₙ = C(n−1, 0) + C(n−2, 1) + C(n−3, 2) + … + C(n−k, k−1)，k = ⌊(n+1)/2⌋

因为下面比上面大的 C(p, q) = 0，也可以写成 fₙ = Σ C(n−1−k, k)，k 从 0 到 n−1。

为什么（计数的理由）：C(n−1−k, k) 正好是 1×(n−1) 棋盘上恰好用 k 块 1×2 骨牌的铺法数。这样的铺法有 k 块 1×2 和 n−1−2k 块单格，一共 n−1−k 块排成一排，从中选哪 k 块是 1×2，C(n−1−k, k) 种。对 k 求和就是 1×(n−1) 的全部铺法 bₙ₋₁ = fₙ。例：1×4 棋盘，k = 0 有 1111（1 种），k = 1 有 211、121、112（3 种），k = 2 有 22（1 种），合计 5 = f₅。

讲义的证明（幻灯片 307–308）：设 gₙ = Σ C(n−1−k, k)，证明它满足 Fibonacci 递推、初值也一样。拿 n = 6 看那一步在干什么：

g₅ + g₄ = [C(4,0) + C(3,1) + C(2,2)] + [C(3,0) + C(2,1)]
= C(4,0) + [C(3,1) + C(3,0)] + [C(2,2) + C(2,1)]
= C(5,0) + C(4,1) + C(3,2) = g₆

中间两对用的是 Pascal 公式 C(m, j) + C(m, j−1) = C(m+1, j)；第一项 C(4,0) = 1 = C(5,0)。一般的 n 完全一样地两两配对。初值：g₀ 是空和，等于 0；g₁ = C(0,0) = 1。所以 gₙ 就是 fₙ。

3　常系数线性齐次递推：特征方程（幻灯片 309–318）

先给递推关系分类（幻灯片 309–311）

为什么要分类：第2节的办法（猜 qⁿ，再把几个解混合）对 Fibonacci 管用。那对第6课的错排数 Dₙ、对 n! 管不管用？要回答这个，先得说清楚 Fibonacci 递推是"哪一类"。先看几个已经见过的递推：

  1. Fibonacci：fₙ = fₙ₋₁ + fₙ₋₂。
  2. 错排（第6课）：Dₙ = (n−1)Dₙ₋₁ + (n−1)Dₙ₋₂，还有 Dₙ = nDₙ₋₁ + (−1)ⁿ。
  3. 阶乘 hₙ = n!：hₙ = n·hₙ₋₁。
  4. 等比 hₙ = qⁿ：hₙ = q·hₙ₋₁。

它们都是同一个样子：前面若干项各乘一个系数再相加，最后可能再加一个和 h 无关的项。

k 阶线性递推（7.10）：hₙ = a₁hₙ₋₁ + a₂hₙ₋₂ + … + aₖhₙ₋ₖ + bₙ　（n ≥ k），aₖ ≠ 0

a₁, …, aₖ 和 bₙ 都可以跟 n 有关。bₙ = 0 时叫齐次；a₁, …, aₖ 都是常数时叫常系数。

词的意思："线性"是说 h 只被乘上系数再相加，没有 hₙ₋₁·hₙ₋₂ 或 hₙ₋₁² 这种项；"k 阶"是说最远往回看 k 项。要求 aₖ ≠ 0，是因为 aₖ = 0 时实际上没有用到 hₙ₋ₖ，阶数其实更低。用这几个词给上面的例子归类（幻灯片 309–311）：

  1. Fibonacci：2 阶，a₁ = a₂ = 1，bₙ = 0。齐次、常系数。
  2. Dₙ = (n−1)Dₙ₋₁ + (n−1)Dₙ₋₂：2 阶，齐次，但系数 n−1 随 n 变，不是常系数。
  3. Dₙ = nDₙ₋₁ + (−1)ⁿ：1 阶，a₁ = n，bₙ = (−1)ⁿ ≠ 0，不齐次。
  4. hₙ = n·hₙ₋₁：1 阶，齐次，a₁ = n 不是常数。
  5. hₙ = q·hₙ₋₁：1 阶，齐次，常系数。

为什么"常系数"这么重要（幻灯片 312）

拿 n! 的递推试一下猜 qⁿ：qⁿ = n·qⁿ⁻¹，约掉得 q = n。q 必须随 n 变，可 q 应该是一个固定的数，所以猜不出来。

换成常系数的 hₙ − a₁hₙ₋₁ − … − aₖhₙ₋ₖ = 0，代入 hₙ = qⁿ：

qⁿ − a₁qⁿ⁻¹ − … − aₖqⁿ⁻ᵏ = qⁿ⁻ᵏ·(qᵏ − a₁qᵏ⁻¹ − … − aₖ) = 0

括号里没有 n：只要 q 是括号这个多项式的根，对所有 n 都成立。这正是 Fibonacci 那一步的推广。

定理（7.13–7.14）：q ≠ 0。hₙ = qⁿ 是 hₙ − a₁hₙ₋₁ − … − aₖhₙ₋ₖ = 0 的解，当且仅当 q 是

xᵏ − a₁xᵏ⁻¹ − a₂xᵏ⁻² − … − aₖ = 0

的根。这个方程叫递推的特征方程，它的根叫特征根。

写特征方程的快办法：把递推写成"hₙ − … = 0"，然后把 hₙ 换成 xᵏ，hₙ₋₁ 换成 xᵏ⁻¹，……，hₙ₋ₖ 换成 x⁰ = 1。下标往回退几步，x 的次数就降几次。因为 aₖ ≠ 0，常数项不为 0，所以 0 不是根，不用担心 q = 0。

k 个不同的根：通解（幻灯片 313）

特征方程有 k 个互不相同的根 q₁, …, qₖ 时，

hₙ = c₁q₁ⁿ + c₂q₂ⁿ + … + cₖqₖⁿ　（7.15）

是通解：不管给什么初值 h₀, …, hₖ₋₁，总能找到常数 c₁, …, cₖ，使 (7.15) 就是满足递推和初值的那个唯一的数列。

为什么，分三步：

  1. 每个 qᵢⁿ 都是解，它们的线性组合也是解（理由和第2节"混合"一样）。
  2. 把 n = 0, 1, …, k−1 代进去，得到 k 个未知数 c₁, …, cₖ 的 k 个一次方程。根互不相同时，这个方程组总有唯一解（它的系数矩阵是 Vandermonde 矩阵，行列式是所有 (qⱼ − qᵢ) 的乘积，不为 0）。所以任何初值都能对上。
  3. 递推加上前 k 个值就决定了后面所有项，所以对上前 k 个值，整个数列就对上了。

做题的步骤：① 写特征方程；② 求 k 个根；③ 写出通解；④ 代 n = 0, …, k−1 解出 c；⑤ 用递推多算一两项，和公式对一下。

完整的例子（幻灯片 314–315）

解 hₙ = 2hₙ₋₁ + hₙ₋₂ − 2hₙ₋₃（n ≥ 3），h₀ = 1，h₁ = 2，h₂ = 0。

第 0 步：先用递推算几项，最后拿来核对：

h₃ = 2·0 + 2 − 2·1 = 0
h₄ = 2·0 + 0 − 2·2 = −4
h₅ = 2·(−4) + 0 − 2·0 = −8
h₆ = 2·(−8) + (−4) − 2·0 = −20
  1. 特征方程：hₙ − 2hₙ₋₁ − hₙ₋₂ + 2hₙ₋₃ = 0，换成 x³ − 2x² − x + 2 = 0。
  2. 求根：整数根一定整除常数项 2（若 r 是根，则 r·(r² − 2r − 1) = −2，r 是 2 的因数），所以只试 ±1、±2：x = 1 得 1 − 2 − 1 + 2 = 0；x = −1 得 −1 − 2 + 1 + 2 = 0；x = 2 得 8 − 8 − 2 + 2 = 0。三个根 1、−1、2。（也可以分组：x²(x−2) − (x−2) = (x−2)(x−1)(x+1)。）
  3. 通解：hₙ = c₁·1ⁿ + c₂(−1)ⁿ + c₃·2ⁿ = c₁ + c₂(−1)ⁿ + c₃·2ⁿ。
  4. 代初值：
    (n=0)　c₁ + c₂ + c₃ = 1
    (n=1)　c₁ − c₂ + 2c₃ = 2
    (n=2)　c₁ + c₂ + 4c₃ = 0
    第 3 式减第 1 式：3c₃ = −1，c₃ = −1/3。第 1 式减第 2 式：2c₂ − c₃ = −1，所以 2c₂ = −1 + c₃ = −4/3，c₂ = −2/3。最后 c₁ = 1 − c₂ − c₃ = 1 + 2/3 + 1/3 = 2。
  5. 结果并核对：hₙ = 2 − (2/3)(−1)ⁿ − (1/3)·2ⁿ。n = 4：2 − 2/3 − 16/3 = 2 − 6 = −4；n = 5：2 + 2/3 − 32/3 = 2 − 10 = −8。和第 0 步一样。

公式里有分数，结果却总是整数：hₙ = (6 − 2(−1)ⁿ − 2ⁿ)/3。把 2ⁿ 写成 (3 − 1)ⁿ 用二项式定理展开，除了最后一项 (−1)ⁿ，每一项都含因子 3，所以 2ⁿ − (−1)ⁿ 是 3 的倍数，2ⁿ + 2(−1)ⁿ = [2ⁿ − (−1)ⁿ] + 3(−1)ⁿ 也是。

演示：递推和通项逐项对账

"用递推算"那一列只用表里前面已经算好的项；"用通项算"那一列直接把 n 代进公式，和前面的项无关。两列每一行都相等，就说明公式对。含 √ 的公式电脑只能算近似值，所以显示成小数，四舍五入后和递推一致。下拉菜单里还有后面几节的例子。

应用：不许出现两个连续 a 的词（幻灯片 315–318）

只用字母 a、b、c 组成长度为 n 的词，要求没有两个 a 挨在一起。有多少个？设为 hₙ。

先数小的：h₀ = 1（空词）；h₁ = 3（a、b、c）；长度 2 的词一共 3² = 9 个，去掉 aa，h₂ = 8。

按第一个字母分类（n ≥ 2）：

  1. 第一个字母是 b 或 c（2 种）：后面 n−1 个字母只要自己没有 aa 就行，hₙ₋₁ 种。小计 2hₙ₋₁。
  2. 第一个字母是 a：第二个字母不能是 a，只能是 b 或 c（2 种）；再后面 n−2 个字母随便组成合法的词，hₙ₋₂ 种。小计 2hₙ₋₂。为什么后面可以随便：两个 a 相邻的危险只出在第 1、2 位之间，第 2 位已经是 b 或 c，后面的词以 a 开头也没关系。

hₙ = 2hₙ₋₁ + 2hₙ₋₂（n ≥ 2），h₀ = 1，h₁ = 3

核对 h₂ = 2·3 + 2·1 = 8，和直接数的一样。再算 h₃ = 2·8 + 2·3 = 22。

  1. 特征方程 x² − 2x − 2 = 0，根 q₁ = 1 + √3，q₂ = 1 − √3（不同的两个根）。
  2. 通解 hₙ = c₁(1+√3)ⁿ + c₂(1−√3)ⁿ。
  3. n = 0：c₁ + c₂ = 1。n = 1：c₁(1+√3) + c₂(1−√3) = 3，减去第一式得 (c₁ − c₂)√3 = 2，c₁ − c₂ = 2/√3。
  4. 解出 c₁ = (2+√3)/(2√3)，c₂ = (−2+√3)/(2√3)。

hₙ = ((2+√3)/(2√3))·(1+√3)ⁿ + ((−2+√3)/(2√3))·(1−√3)ⁿ　（n ≥ 0）

前几项 1, 3, 8, 22, 60, 164, 448, …（演示里选"不许 aa 的词"可以对账；我们也用程序把长度 ≤ 8 的词全部列出来数过）。

4　特征根有重根（幻灯片 319–324）

出问题了：两个根一样（幻灯片 319–320）

解 hₙ = 4hₙ₋₁ − 4hₙ₋₂，h₀ = 1，h₁ = 3。用递推算：1, 3, 8, 20, 48, 112, …

特征方程 x² − 4x + 4 = (x − 2)² = 0，两个根都是 2（叫二重根）。照第3节的做法写通解：

hₙ = c₁·2ⁿ + c₂·2ⁿ = (c₁ + c₂)·2ⁿ = c·2ⁿ

看起来有两个常数，其实合并成了一个 c。代初值：n = 0 得 c = 1，n = 1 得 2c = 3，c = 3/2。矛盾。原因：两个初值需要两个真正不同的"积木"来拼，两个根重合，我们就少了一块积木。

缺的那一块是 n·2ⁿ（幻灯片 321）

讲义说 n·2ⁿ 也是解。先直接代进去验证：右边

4(n−1)·2ⁿ⁻¹ − 4(n−2)·2ⁿ⁻² = 2ⁿ·[2(n−1) − (n−2)] = 2ⁿ·n

正好等于左边 n·2ⁿ。

为什么偏偏重根时乘 n 能行：对一般的 2 阶递推 hₙ = a₁hₙ₋₁ + a₂hₙ₋₂，q 是特征根，代入 hₙ = n·qⁿ，把左边减右边整理：

n·qⁿ − a₁(n−1)qⁿ⁻¹ − a₂(n−2)qⁿ⁻² = qⁿ⁻²·[ n·(q² − a₁q − a₂) + (a₁q + 2a₂) ]

  1. 第一部分 q² − a₁q − a₂ = 0，因为 q 是特征根。
  2. 剩下 a₁q + 2a₂。q 是二重根时特征多项式是 (x − q)² = x² − 2qx + q²，即 a₁ = 2q，a₂ = −q²，于是 a₁q + 2a₂ = 2q² − 2q² = 0。这个例子里 4·2 + 2·(−4) = 0。
  3. 如果 q 只是单根，这一项一般不为 0。例：hₙ = 3hₙ₋₁ − 2hₙ₋₂（根 1 和 2），取 q = 2 得 3·2 + 2·(−2) = 2 ≠ 0，所以 n·2ⁿ 不是它的解。

所以"乘 n"恰好是二重根才允许的事。第7节用生成函数还会看到另一个解释：1/(1−2x)² 展开后 xⁿ 的系数是 (n+1)·2ⁿ，n 自己就冒出来了。

回到例子，通解 hₙ = c₁·2ⁿ + c₂·n·2ⁿ（7.17）：

  1. n = 0：c₁ = 1。
  2. n = 1：2c₁ + 2c₂ = 3，所以 c₂ = 1/2。
  3. hₙ = 2ⁿ + n·2ⁿ⁻¹ = (n+2)·2ⁿ⁻¹。核对：n = 3 时 5·4 = 20，n = 4 时 6·8 = 48。

一般规则（幻灯片 322）

定理（7.18–7.19）：设特征方程的不同的根是 q₁, …, qₜ，其中 qᵢ 是 sᵢ 重根。qᵢ 在通解里对应的部分是

Hₙ⁽ⁱ⁾ = (c₁ + c₂n + c₃n² + … + csᵢ·nsᵢ−1)·qᵢⁿ

通解是 hₙ = Hₙ⁽¹⁾ + Hₙ⁽²⁾ + … + Hₙ⁽ᵗ⁾。

为什么常数的个数刚好够：sᵢ 重根贡献 sᵢ 个常数，所有 sᵢ 加起来是特征方程的次数 k，正好等于初值的个数。三重根时多出来的 n²·qⁿ 也是解，理由和上面一样，只是要多验证一层（三重根让下一个余项也变成 0）。

幻灯片 322 的递推印成了 "hₙ = a₁bₙ₋₁ + …"，应为 a₁hₙ₋₁。

例：一个三重根（幻灯片 323–324）

解 hₙ = −hₙ₋₁ + 3hₙ₋₂ + 5hₙ₋₃ + 2hₙ₋₄（n ≥ 4），h₀ = 1，h₁ = 0，h₂ = 1，h₃ = 2。先用递推算两项：h₄ = −2 + 3·1 + 5·0 + 2·1 = 3，h₅ = −3 + 3·2 + 5·1 + 2·0 = 8。

  1. 特征方程 x⁴ + x³ − 3x² − 5x − 2 = 0。试常数项 −2 的因数：x = −1 得 1 − 1 − 3 + 5 − 2 = 0；x = 2 得 16 + 8 − 12 − 10 − 2 = 0。把 (x+1) 除尽，得到 x⁴ + x³ − 3x² − 5x − 2 = (x + 1)³(x − 2)。展开核对：(x³ + 3x² + 3x + 1)(x − 2) = x⁴ + x³ − 3x² − 5x − 2。所以 −1 是三重根，2 是单根。
  2. 通解 hₙ = (c₁ + c₂n + c₃n²)(−1)ⁿ + c₄·2ⁿ。
  3. 代 n = 0, 1, 2, 3：
    (n=0)　 c₁　　　　　　　 + c₄ = 1
    (n=1)　−c₁ − c₂ − c₃ + 2c₄ = 0
    (n=2)　 c₁ + 2c₂ + 4c₃ + 4c₄ = 1
    (n=3)　−c₁ − 3c₂ − 9c₃ + 8c₄ = 2
    解是 c₁ = 7/9，c₂ = −3/9，c₃ = 0，c₄ = 2/9。解完一定要代回去检查：(n=1) −7/9 + 3/9 − 0 + 4/9 = 0；(n=2) 7/9 − 6/9 + 0 + 8/9 = 1；(n=3) −7/9 + 9/9 − 0 + 16/9 = 2。都对。
  4. hₙ = (7/9)(−1)ⁿ − (3/9)·n(−1)ⁿ + (2/9)·2ⁿ。核对 h₄ = (7 − 12 + 32)/9 = 3，h₅ = (−7 + 15 + 64)/9 = 8。

5　非齐次递推（幻灯片 325–335）

汉诺塔（幻灯片 325–327）

三根柱子，一根上套着 n 个大小不同的圆盘，大的在下。每次移动一个盘子，任何时候都不能把大盘子放在小盘子上面。把整摞移到另一根柱子上，至少要几步？设为 hₙ。

小的情形：h₀ = 0；h₁ = 1；h₂ = 3（小的挪到中间，大的挪到目标，小的再放上去）。

递推的理由：最大的盘子总得动一次。它动的那一刻，它上面不能有盘子，它要去的柱子也必须是空的，所以其余 n−1 个盘子全在第三根柱子上。于是：先把上面 n−1 个移开（hₙ₋₁ 步），再移最大的（1 步），再把 n−1 个移回到它上面（hₙ₋₁ 步）。

h₀ = 0，hₙ = 2hₙ₋₁ + 1　（n ≥ 1）　（7.20）

这里多了一个 "+1"，bₙ = 1 ≠ 0，是非齐次递推。这个简单的可以一层层代下去（迭代）：

hₙ = 2hₙ₋₁ + 1 = 2(2hₙ₋₂ + 1) + 1 = 2²hₙ₋₂ + 2 + 1
= 2³hₙ₋₃ + 2² + 2 + 1 = … = 2ⁿ⁻¹ + 2ⁿ⁻² + … + 2 + 1 = 2ⁿ − 1　（7.21）

h₃ = 7，h₄ = 15。64 个盘子要 2⁶⁴ − 1 ≈ 1.8 × 10¹⁹ 步。讲义还提到：柱子有 4 根或更多时，最少要几步是一个没有解决的问题（这是课本写作时的说法；4 根柱子的情形后来在 2014 年被证明，5 根及以上仍未解决）。

迭代算不动的时候：齐次通解 + 特解（幻灯片 327–330）

例：hₙ = 3hₙ₋₁ − 4n（n ≥ 1），h₀ = 2。迭代会得到 3ⁿh₀ − 4[n + 3(n−1) + 3²(n−2) + …]，括号里的和不好算。换个思路。先用递推算几项：

h₀ = 2，h₁ = 3·2 − 4 = 2，h₂ = 3·2 − 8 = −2，h₃ = 3·(−2) − 12 = −18，h₄ = 3·(−18) − 16 = −70

假设有人告诉你 pₙ = 2n + 3 也满足这个递推（验证：3·(2(n−1) + 3) − 4n = 6n + 3 − 4n = 2n + 3），只是初值 p₀ = 3 不对。把两串数相减：

hₙ − pₙ：2 − 3, 2 − 5, −2 − 7, −18 − 9, −70 − 11 = −1, −3, −9, −27, −81

差是一个公比为 3 的等比数列，也就是齐次递推 hₙ = 3hₙ₋₁ 的解。为什么：(3hₙ₋₁ − 4n) − (3pₙ₋₁ − 4n) = 3(hₙ₋₁ − pₙ₋₁)，那个 −4n 被减掉了。

所以：任何一个解 = 一个特解 + 齐次递推的某个解。方法是（幻灯片 330）：

  1. 求对应齐次递推的通解。这里 hₙ = 3hₙ₋₁，特征方程 x − 3 = 0，通解 c·3ⁿ（7.23）。
  2. 求非齐次递推的一个特解。
  3. 两者相加，最后才用初值定出常数。

特解 2n + 3 是怎么找到的（幻灯片 328–329）：bₙ = −4n 是 n 的一次式。把一次式 rn + s 放进 hₙ − 3hₙ₋₁，出来的还是一次式，所以有希望凑出 −4n。代入：

rn + s = 3(r(n−1) + s) − 4n = (3r − 4)n + (3s − 3r)

对所有 n 都相等，所以 n 的系数、常数项分别相等：r = 3r − 4，得 r = 2；s = 3s − 3r，得 2s = 3r = 6，s = 3。特解 hₙ = 2n + 3（7.26）。

合起来 hₙ = c·3ⁿ + 2n + 3（7.27）。h₀ = 2：c + 3 = 2，c = −1。

hₙ = −3ⁿ + 2n + 3　（n ≥ 0）

核对 h₃ = −27 + 6 + 3 = −18。为什么初值放在最后用：特解只负责凑出 −4n，它不管初值；能调节的只有齐次部分的常数 c。如果先拿初值去定 c、再加特解，加上特解后初值就又不对了。

特解该猜成什么样子（幻灯片 330–331）

bₙ 是 n 的 k 次多项式，就猜一个 k 次多项式：

　bₙ = d（常数）→ 试 hₙ = r；bₙ = dn + e → 试 rn + s；bₙ = fn² + dn + e → 试 rn² + sn + t

bₙ 是指数 dⁿ，就猜 hₙ = p·dⁿ。

为什么：hₙ − a·hₙ₋₁ 把 k 次多项式变成 k 次多项式（a ≠ 1 时最高次项不会抵消），把 dⁿ 变成 dⁿ 的倍数（dⁿ − a·dⁿ⁻¹ = (1 − a/d)·dⁿ）。所以"同样形状"的猜测放进去，出来的还是同样形状，只要调系数去配 bₙ。

例（幻灯片 331–332）：hₙ = 2hₙ₋₁ + 3ⁿ，h₀ = 2。

  1. 齐次部分：特征根 2，通解 c·2ⁿ。
  2. 特解试 p·3ⁿ：p·3ⁿ = 2p·3ⁿ⁻¹ + 3ⁿ，两边除以 3ⁿ⁻¹ 得 3p = 2p + 3，p = 3。
  3. hₙ = c·2ⁿ + 3·3ⁿ，h₀ = 2：c + 3 = 2，c = −1。

hₙ = 3ⁿ⁺¹ − 2ⁿ　（n ≥ 0）

核对：h₁ = 2·2 + 3 = 7 = 9 − 2；h₂ = 2·7 + 9 = 23 = 27 − 4。

两种"撞车"的情况（幻灯片 332–335）

情况一：a = 1，即 hₙ = hₙ₋₁ + bₙ（7.28）。这时猜多项式不灵：比如 bₙ = d，试 hₙ = r，得 r = r + d，不可能。原因是 hₙ − hₙ₋₁ 会把多项式的次数降一次（常数减常数是 0）。好在这种递推直接迭代就行：

hₙ = h₀ + b₁ + b₂ + … + bₙ

解递推就变成了求和。例（幻灯片 333）：hₙ = hₙ₋₁ + n³，h₀ = 0，于是

hₙ = 0³ + 1³ + 2³ + … + n³ = [n(n+1)/2]² = n²(n+1)²/4

核对：h₁ = 1，h₂ = 1 + 8 = 9 = 4·9/4。注意：幻灯片 333 印的是 (n+1)²(n+2)²/4，下标错了一位：n = 1 时它给出 4·9/4 = 9，而 h₁ = 1。

情况二：bₙ = dⁿ，而 d 恰好是特征根。例（幻灯片 334–335）：hₙ = 3hₙ₋₁ + 3ⁿ，h₀ = 2。

  1. 试 p·3ⁿ：p·3ⁿ = 3p·3ⁿ⁻¹ + 3ⁿ，除以 3ⁿ 得 p = p + 1，不可能。为什么：3ⁿ 本身就是齐次递推 hₙ = 3hₙ₋₁ 的解，把 p·3ⁿ 放进 hₙ − 3hₙ₋₁ 只会得到 0，永远凑不出 3ⁿ。
  2. 改试 p·n·3ⁿ（和重根一样"乘 n"）：p·n·3ⁿ = 3p(n−1)·3ⁿ⁻¹ + 3ⁿ，除以 3ⁿ 得 pn = p(n−1) + 1，p = 1。
  3. 通解 hₙ = c·3ⁿ + n·3ⁿ，h₀ = 2 得 c = 2。

hₙ = 2·3ⁿ + n·3ⁿ = (n+2)·3ⁿ　（n ≥ 0）

核对：h₁ = 3·2 + 3 = 9 = 3·3；h₂ = 3·9 + 9 = 36 = 4·9。

两种情况其实是一回事：a = 1 时特征根是 1，而多项式可以看成"乘了 1ⁿ"；bₙ 和齐次解撞车，就要把猜测乘上 n（所以 a = 1 时常数要猜成 rn，一次式要猜成二次式）。上面演示的下拉菜单里有汉诺塔和这一节的三个例子。

6　生成函数（幻灯片 336–347）

为什么需要新工具

前面的问题都先找出递推，再解递推。可是像"从苹果、香蕉、橘子、梨里拿 n 个水果，苹果偶数个、香蕉奇数个、橘子最多 4 个、梨至少 1 个，有几种拿法"这种问题，递推很难找，手工列举又太多。生成函数把"每种东西拿几个"变成多项式乘法，让乘法替我们数。

先看一个能手数的小例子。苹果最多拿 2 个，香蕉最多拿 1 个（同种水果之间没有区别）。一共拿 n 个有几种？把 (苹果数, 香蕉数) 列出来：

  1. n = 0：(0, 0)，1 种。
  2. n = 1：(1, 0)、(0, 1)，2 种。
  3. n = 2：(2, 0)、(1, 1)，2 种。
  4. n = 3：(2, 1)，1 种。

现在算 (1 + x + x²)(1 + x)。展开就是从每个括号里各挑一项相乘，一共 3 × 2 = 6 种挑法：

1·1 = 1　　1·x = x　　x·1 = x　　x·x = x²　　x²·1 = x²　　x²·x = x³
合并同类项：1 + 2x + 2x² + x³

系数 1, 2, 2, 1，和上面数出来的一样。这不是巧合：

  1. 第一个括号里的 xᵃ 表示"拿 a 个苹果"（a = 0, 1, 2），第二个括号里的 xᵇ 表示"拿 b 个香蕉"。括号里写的正是每种水果允许的个数。
  2. 从每个括号各挑一项，就是给每种水果各做一个决定。例如挑 x² 和 x，就是"2 个苹果、1 个香蕉"。
  3. xᵃ·xᵇ = xᵃ⁺ᵇ：指数相加，所以乘出来的指数正好是水果总数。
  4. 合并同类项就是把"总数相同"的拿法放在一起数，所以 xⁿ 的系数 = 一共拿 n 个的拿法数。

"x 只是一个占位符"是什么意思：我们从来不给 x 代具体的数。xⁿ 像一个贴着标签"第 n 号"的格子，系数是格子里装的数。把整串数写成 h₀ + h₁x + h₂x² + … 只是一种记账方式，好处是乘法会自动把"挑法"按总数归类。

定义（幻灯片 336）：数列 h₀, h₁, h₂, … 的生成函数是无穷级数

g(x) = h₀ + h₁x + h₂x² + … + hₙxⁿ + …

xⁿ 的系数就是 hₙ，xⁿ 是给 hₙ 占位置的。

几个常用的生成函数（幻灯片 336–338）

  1. 1, 1, 1, … 的生成函数是 1/(1−x)。为什么：(1 − x)(1 + x + x² + …) = 1 + x + x² + … − x − x² − … = 1，所以 1 + x + x² + … 就是 1/(1−x)。计数意思：一种东西，拿几个都行，每个个数恰好 1 种拿法。
  2. C(m,0), C(m,1), …, C(m,m) 的生成函数是 (1+x)ᵐ（第5课的二项式定理）。计数意思：m 个不同的东西，每个一个括号 (1 + x)：不拿（1）或拿（x）。
  3. C(α,0), C(α,1), C(α,2), … 的生成函数是 (1+x)α（第5课的 Newton 二项式定理，α 是实数）。
  4. hₙ = C(n+k−1, n) 的生成函数是 1/(1−x)ᵏ。下面推一下。

1/(1−x)ᵏ 的推导（幻灯片 337–338）：1/(1−x)ᵏ 是 k 个 (1 + x + x² + …) 相乘。从第 i 个括号挑 xeᵢ，乘起来是 xe₁+e₂+…+eₖ。要得到 xⁿ，就要 e₁ + e₂ + … + eₖ = n（7.30）。所以 xⁿ 的系数 = 这个方程的非负整数解的个数 = C(n+k−1, n)（第3课的隔板法）。小例子 k = 2、n = 2：解是 (0,2)、(1,1)、(2,0)，3 个 = C(3,2)；而 1/(1−x)² = 1 + 2x + 3x² + …，x² 的系数正是 3。

每种东西一个括号（幻灯片 338–342）

例 1（幻灯片 338）：(1 + x + x² + x³ + x⁴ + x⁵)(1 + x + x²)(1 + x + x² + x³ + x⁴) 是什么数列的生成函数？

按上面的读法：三个括号代表三种东西，分别能取 0–5、0–2、0–4 个。xⁿ 的系数 hₙ 就是 e₁ + e₂ + e₃ = n、0 ≤ e₁ ≤ 5、0 ≤ e₂ ≤ 2、0 ≤ e₃ ≤ 4 的整数解个数。最多 5 + 2 + 4 = 11，所以 n > 11 时 hₙ = 0。乘出来：

n01234567891011
hₙ1369121414129631

核对 n = 1：(1,0,0)、(0,1,0)、(0,0,1)，3 个。全部加起来是 90 = 6 × 3 × 5，就是每种东西选法数相乘，也就是三个括号都代 x = 1 的结果。下面的演示可以看每乘一个括号系数怎么变，点一个 n 还能把对应的解全部列出来。

例 2（幻灯片 339–341）：苹果偶数个、香蕉奇数个、橘子 0 到 4 个、梨至少 1 个，拿 n 个的方法数 hₙ 的生成函数。每种水果一个括号，括号里的指数就是允许的个数：

g(x) = (1 + x² + x⁴ + …)(x + x³ + x⁵ + …)(1 + x + x² + x³ + x⁴)(x + x² + x³ + …)

每个括号都有简单的写法（幻灯片 340）：

  1. 1 + x² + x⁴ + … = 1/(1−x²)：把 1/(1−y) = 1 + y + y² + … 里的 y 换成 x²。
  2. x + x³ + x⁵ + … = x(1 + x² + x⁴ + …) = x/(1−x²)。
  3. 1 + x + x² + x³ + x⁴ = (1−x⁵)/(1−x)：因为 (1−x)(1 + x + … + x⁴) = 1 − x⁵，中间全抵消。
  4. x + x² + x³ + … = x/(1−x)。

g(x) = (1/(1−x²))·(x/(1−x²))·((1−x⁵)/(1−x))·(x/(1−x)) = x²(1−x⁵) / ((1−x²)²(1−x)²)

这个分式展开后的系数就是答案（讲义说"Taylor 级数的系数数的正是这种组合"）。前几项 0, 0, 1, 2, 5, 8, 14, 19, 28, …。核对 h₂ = 1：至少 1 个香蕉、至少 1 个梨，2 个水果只能是"1 香蕉 + 1 梨"。h₃ = 2："1 香蕉 + 2 梨"和"1 香蕉 + 1 橘子 + 1 梨"。

例 3（幻灯片 341–342）：苹果偶数个、香蕉是 5 的倍数、橘子最多 4 个、梨 0 或 1 个。先把 n ≤ 3 的情形全列出来（讲义表格里每一列就是一袋）：

  1. n = 0：空袋子。1 种。
  2. n = 1：1 梨；1 橘子。2 种。
  3. n = 2：2 苹果；2 橘子；1 橘子 + 1 梨。3 种。
  4. n = 3：2 苹果 + 1 梨；2 苹果 + 1 橘子；3 橘子；2 橘子 + 1 梨。4 种。

看起来 hₙ = n + 1。用生成函数证明：

g(x) = (1 + x² + …)(1 + x⁵ + x¹⁰ + …)(1 + x + … + x⁴)(1 + x)
= (1/(1−x²)) · (1/(1−x⁵)) · ((1−x⁵)/(1−x)) · (1+x)
= 1/(1−x)² = Σ C(n+1, n)xⁿ = Σ (n+1)xⁿ

化简的两步：1−x⁵ 上下约掉；1−x² = (1−x)(1+x)，所以 (1+x)/(1−x²) = 1/(1−x)。于是 hₙ = n + 1。

方程的解也是"拿东西"（幻灯片 343–347）

奇数解（幻灯片 343–344）：e₁ + e₂ + … + eₖ = n，每个 eᵢ 都是正奇数。每个变量一个括号 (x + x³ + x⁵ + …) = x/(1−x²)，所以

g(x) = (x/(1−x²))ᵏ = xᵏ/(1−x²)ᵏ

核对 k = 2、n = 4：奇数解 (1,3)、(3,1)，2 个；x²/(1−x²)² = x²(1 + 2x² + 3x⁴ + …)，x⁴ 的系数是 2。

带系数的方程（幻灯片 345–346）：3e₁ + 4e₂ + 2e₃ + 5e₄ = n 的非负整数解个数。为什么可以换元：令 f₁ = 3e₁，f₁ 就是"第一个变量贡献的量"，只能是 0, 3, 6, …；同理 f₂ 是 4 的倍数，f₃ 是偶数，f₄ 是 5 的倍数。问题变成 f₁ + f₂ + f₃ + f₄ = n、每个 fᵢ 在各自允许的集合里，每个变量一个括号：

g(x) = (1 + x³ + x⁶ + …)(1 + x⁴ + x⁸ + …)(1 + x² + x⁴ + …)(1 + x⁵ + x¹⁰ + …) = 1/((1−x³)(1−x⁴)(1−x²)(1−x⁵))

找零钱（幻灯片 347）：1 分、5 分、10 分、25 分、50 分硬币都有无限多个，凑出 n 分有几种方法？这就是 e₁ + 5e₂ + 10e₃ + 25e₄ + 50e₅ = n 的解数：

g(x) = 1/((1−x)(1−x⁵)(1−x¹⁰)(1−x²⁵)(1−x⁵⁰))

例：10 分有 4 种（10 个 1 分；1 个 5 分 + 5 个 1 分；2 个 5 分；1 个 10 分）。25 分有 13 种，1 元（100 分）有 292 种。上面演示里选"找零钱"可以看 25 分以内的每一种。

7　用生成函数解递推（幻灯片 348–360）

两个工具（幻灯片 348–349）

把第5课的 (5.14) 里的 z 换成 rx，就得到

1/(1−rx)ⁿ = Σ C(n+k−1, k)·rᵏxᵏ　（k 从 0 到 ∞，|x| < 1/|r|）　（7.31）

最常用的两个：1/(1−rx) = Σ rᵏxᵏ；1/(1−rx)² = Σ (k+1)rᵏxᵏ。

例：平方数 0, 1, 4, 9, … 的生成函数。想法是从 1/(1−x)² = 1 + 2x + 3x² + … 出发，用两种操作把系数变成 n²：

  1. 乘 x 是"整体右移一格"：x/(1−x)² = x + 2x² + 3x³ + … = Σ n·xⁿ。每个系数挪到下一号格子，于是 xⁿ 的系数变成 n。
  2. 求导再乘 x 是"第 n 项乘 n"：(xⁿ)′ = n·xⁿ⁻¹，再乘 x 回到 xⁿ，所以 xⁿ 的系数被乘上 n。对 x/(1−x)² 求导：
    (x/(1−x)²)′ = [(1−x)² + 2x(1−x)]/(1−x)⁴ = [(1−x) + 2x]/(1−x)³ = (1+x)/(1−x)³
    = 1 + 2²x + 3²x² + … + n²xⁿ⁻¹ + …
  3. 再乘 x：x(1+x)/(1−x)³ = x + 2²x² + 3²x³ + … + n²xⁿ + …

核对：x(1+x)/(1−x)³ = (x + x²)(1 + 3x + 6x² + 10x³ + …) = x + (3+1)x² + (6+3)x³ + (10+6)x⁴ + … = x + 4x² + 9x³ + 16x⁴ + …。

完整的例子（幻灯片 350–352）

为什么还要另一种解法：第3、4节要先知道"该猜 qⁿ，重根时猜 nqⁿ"。生成函数的方法是机械的，不用猜，重根的情形也会自己冒出来。

解 hₙ = 5hₙ₋₁ − 6hₙ₋₂（n ≥ 2），h₀ = 1，h₁ = −2。用递推算：1, −2, −16, −68, −244, …

设 g(x) = h₀ + h₁x + h₂x² + …。把 g、−5x·g、6x²·g 按 x 的次数对齐写出来（乘 x 就是右移一格），先用真实的数看：

x⁰x¹x²x³xⁿ
g(x)1−2−16−68hₙ
−5x·g(x)0−51080−5hₙ₋₁
6x²·g(x)006−126hₙ₋₂
三行相加1−7000

为什么从 x² 起全是 0：xⁿ 那一列加起来是 hₙ − 5hₙ₋₁ + 6hₙ₋₂，按递推正好是 0。只有前两列（还没"凑齐"三项，只涉及初值）留下来：h₀ = 1 和 h₁ − 5h₀ = −7。所以

(1 − 5x + 6x²)·g(x) = 1 − 7x，　g(x) = (1 − 7x)/(1 − 5x + 6x²)

拆成部分分式（幻灯片 351）：1 − 5x + 6x² = (1 − 2x)(1 − 3x)，设

(1 − 7x)/((1−2x)(1−3x)) = A/(1−2x) + B/(1−3x)，即 1 − 7x = A(1−3x) + B(1−2x)

  1. 代 x = 1/2（让 B 那项消失）：1 − 7/2 = A(1 − 3/2)，−5/2 = −A/2，A = 5。
  2. 代 x = 1/3（让 A 那项消失）：1 − 7/3 = B(1 − 2/3)，−4/3 = B/3，B = −4。
  3. 为什么可以随便代 x：这是两个多项式相等的恒等式，对所有 x 都成立，挑能消掉一项的 x 最省事。

于是 g(x) = 5/(1−2x) − 4/(1−3x) = 5Σ2ⁿxⁿ − 4Σ3ⁿxⁿ，读出系数：

hₙ = 5·2ⁿ − 4·3ⁿ

核对 h₂ = 20 − 36 = −16，h₃ = 40 − 108 = −68。

和特征方程的联系：分母 1 − 5x + 6x² 和特征多项式 x² − 5x + 6 的系数正好倒过来（1 − 5x + 6x² = x²·((1/x)² − 5(1/x) + 6)）。特征根 2、3 就以 1 − 2x、1 − 3x 的形式出现在分母里，最后变成 2ⁿ、3ⁿ。

重根会自己冒出来（幻灯片 352–355）

解 hₙ + hₙ₋₁ − 16hₙ₋₂ + 20hₙ₋₃ = 0（n ≥ 3），h₀ = 0，h₁ = 1，h₂ = −1。用递推算：0, 1, −1, 17, −53, 345, −1533, …

  1. 同样对齐 g、x·g、−16x²·g、20x³·g 四行。x⁰ 列：h₀ = 0；x¹ 列：h₁ + h₀ = 1；x² 列：h₂ + h₁ − 16h₀ = −1 + 1 − 0 = 0；x³ 起每列按递推是 0。所以 (1 + x − 16x² + 20x³)·g(x) = x。
  2. 分母因式分解：1 + x − 16x² + 20x³ = (1 − 2x)²(1 + 5x)。展开核对：(1 − 4x + 4x²)(1 + 5x) = 1 + x − 16x² + 20x³。（对应特征方程 x³ + x² − 16x + 20 = (x−2)²(x+5)，2 是二重根。）
  3. 部分分式要写成 A/(1−2x) + B/(1−2x)² + C/(1+5x)。为什么平方因子要配两项：(1−2x)² 在分母里，拆开后可能同时有 1/(1−2x) 和 1/(1−2x)² 两部分，少写一项就凑不出来。两边乘分母：
    x = A(1−2x)(1+5x) + B(1+5x) + C(1−2x)²
    x = 1/2：1/2 = B·(7/2)，B = 1/7 = 7/49
    x = −1/5：−1/5 = C·(7/5)² = 49C/25，C = −5/49
    x = 0：0 = A + B + C，A = −2/49
  4. 展开：1/(1−2x) = Σ2ⁿxⁿ，1/(1−2x)² = Σ(n+1)2ⁿxⁿ，1/(1+5x) = Σ(−5)ⁿxⁿ。

hₙ = −(2/49)·2ⁿ + (7/49)·(n+1)·2ⁿ − (5/49)·(−5)ⁿ　（n ≥ 0）

核对 h₃ = (−16 + 7·4·8 + 625)/49 = 833/49 = 17。这就是重根时出现 n·qⁿ 的另一个解释：分母里的 (1 − 2x)² 展开后系数是 (n+1)·2ⁿ = n·2ⁿ + 2ⁿ。

一般结论（幻灯片 356–360）

上面两个例子的做法对任何常系数线性齐次递推都适用。注意讲义这里把系数移到了左边：

递推 hₙ + a₁hₙ₋₁ + … + aₖhₙ₋ₖ = 0（n ≥ k，aₖ ≠ 0）的生成函数是 g(x) = p(x)/q(x)，其中

q(x) = 1 + a₁x + a₂x² + … + aₖxᵏ（k 次，常数项 1）

p(x) = h₀ + (h₁ + a₁h₀)x + (h₂ + a₁h₁ + a₂h₀)x² + … + (hₖ₋₁ + a₁hₖ₋₂ + … + aₖ₋₁h₀)xᵏ⁻¹（次数 < k）

p(x) 从哪来：就是对齐表格里前 k 列的列和（这些列还没"凑齐"，所以不为 0）。核对第一个例子：那里 a₁ = −5，a₂ = 6，q(x) = 1 − 5x + 6x²，p(x) = h₀ + (h₁ + a₁h₀)x = 1 + (−2 − 5)x = 1 − 7x。

反过来也对（幻灯片 357–359）：给一个分式 p(x)/q(x)，q(x) = b₀ + b₁x + … + bₖxᵏ 是 k 次、b₀ ≠ 0，p(x) 次数 < k。用部分分式和 (7.31) 能展开成 h₀ + h₁x + …。把 p(x) = q(x)·(h₀ + h₁x + …) 两边比较 xⁿ 的系数：

  1. n < k 时（7.32）：b₀h₀ = d₀，b₀h₁ + b₁h₀ = d₁，……。因为 b₀ ≠ 0，可以依次解出 h₀, h₁, …, hₖ₋₁（每个方程只多一个新未知数，叫"三角形方程组"）。
  2. n ≥ k 时（7.33）：p(x) 没有 xⁿ 项，所以 b₀hₙ + b₁hₙ₋₁ + … + bₖhₙ₋ₖ = 0。除以 b₀，就是一个 k 阶常系数线性齐次递推。

小例子：1/(1 − x − x²)。b₀ = 1，b₁ = b₂ = −1，p = 1。h₀ = 1；h₁ − h₀ = 0，h₁ = 1；以后 hₙ − hₙ₋₁ − hₙ₋₂ = 0。得到 1, 1, 2, 3, 5, 8, …，是 Fibonacci 数 fₙ₊₁。

定理（7.34–7.35，幻灯片 360）：满足 k 阶常系数线性齐次递推的数列，生成函数是 p(x)/q(x)，q(x) 是常数项不为 0 的 k 次多项式，p(x) 次数小于 k。反之，任何这样的 p(x)/q(x) 都是某个这种递推的数列的生成函数。

8　一个几何例子：凸多边形的三角剖分（幻灯片 361–369）

这一节的递推不是线性的（里面有两项相乘），特征方程用不上；但生成函数照样能解，最后还要用到第5课的 Newton 二项式定理。答案是下一章的主角 Catalan 数。

凸区域和对角线（幻灯片 361–362）

平面上的一个点集 K 叫凸的，如果 K 里任意两点 p、q 之间的整条线段都还在 K 里。下图 (a) 有一个凹进去的口子，p、q 都在里面，线段却跑到了外面，所以不是凸的。

边界由有限条线段组成的区域叫多边形区域，这些线段叫边，边的交点叫角（顶点）。连接两个不相邻的角的线段叫对角线。n 边形有几条对角线？以六边形为例，讲义给了两种数法：

  1. 从每个角数：每个角连出 6 − 3 = 3 条对角线，6 个角共 6·3 = 18，但每条对角线有两个端点，被数了两次，所以是 9 条。一般是 n(n−3)/2。
  2. 反着数：6 个角两两相连共 C(6,2) = 15 条线段，其中 6 条是边，剩下 15 − 6 = 9 条是对角线。一般是 n(n−1)/2 − n = n(n−3)/2。

三角剖分：先数小的（幻灯片 363–364）

K 是凸的，所以每条对角线都整个在 K 里面，把 K 分成两个较小的凸多边形。不断加入在内部互不相交的对角线，直到全部分成三角形，这叫一个三角剖分。n 边形要用 n − 3 条对角线，分成 n − 2 个三角形。

讲义的记号：hₙ = 凸 (n+1) 边形的三角剖分数。（用 n+1 而不用 n，是为了让最后的公式整齐。）

  1. h₂ = 1：三角形（3 条边）没有对角线，本身就是剖分。
  2. h₃ = 2：四边形，两条对角线选一条。
  3. h₄ = 5：五边形，见下图。
  4. 规定 h₁ = 1：把一条线段看成"只有 2 条边、没有内部的多边形"，它什么都不用做，算 1 种。下面会看到为什么要这样规定。

递推：看底边所在的三角形（幻灯片 364–367）

先用五边形手算。挑一条边 AB 当底边（下图红色）。不管怎么剖分，AB 一定是某一个三角形 T 的边（黄色），T 的第三个顶点只能是 C、D、E 之一。按这个顶点分类：

  1. 顶点是 C：T = ABC。T 的右边只剩边 BC，是一条"线段"（2 条边，h₁ = 1 种）；左边剩四边形 ACDE，有 h₃ = 2 种。共 1 × 2 = 2 种。
  2. 顶点是 D：T = ABD。两边各剩一个三角形 ADE、BCD，各 h₂ = 1 种。共 1 × 1 = 1 种。
  3. 顶点是 E：T = ABE。左边是线段 EA（h₁ = 1），右边是四边形 BCDE（h₃ = 2）。共 2 种。

合计 h₄ = h₁h₃ + h₂h₂ + h₃h₁ = 2 + 1 + 2 = 5。现在能看出为什么规定 h₁ = 1：顶点紧挨着底边时，一侧什么都没剩，"什么都不做"是 1 种方法；规定 h₁ = 1，这种情况就和别的情况用同一个乘积公式。

一般情形：凸 (n+1) 边形，挑一条底边。三角形 T 把剩下的部分分成 K₁ 和 K₂，K₁ 有 k+1 条边，K₂ 有 n−k+1 条边，k = 1, 2, …, n−1（下图）。

  1. K₁、K₂ 接下来各自独立地三角剖分，分别有 hₖ、hₙ₋ₖ 种（K₁ 有 k+1 条边，按记号就是 hₖ）。乘法原理：这个顶点下有 hₖ·hₙ₋ₖ 种。
  2. 不同的顶点给出不同的剖分（T 由剖分唯一决定），所以对 k 相加（加法原理）。

定理（7.36，幻灯片 364）：h₁ = 1，

hₙ = h₁hₙ₋₁ + h₂hₙ₋₂ + … + hₙ₋₁h₁ = Σ hₖhₙ₋ₖ（k 从 1 到 n−1）　（n ≥ 2）

它的解是 hₙ = (1/n)·C(2n−2, n−1)　（7.37）

核对 n = 2：h₁h₁ = 1 = h₂。n = 5：h₁h₄ + h₂h₃ + h₃h₂ + h₄h₁ = 5 + 2 + 2 + 5 = 14，六边形有 14 种。

用生成函数解（幻灯片 367–369）

设 g(x) = h₁x + h₂x² + h₃x³ + …（从 h₁ 开始，没有常数项）。

为什么要算 g(x)²：g(x)·g(x) 里 xⁿ 的系数，是从第一个 g 挑 hₖxᵏ、从第二个 g 挑 hₙ₋ₖxⁿ⁻ᵏ，对所有 k 相加，也就是 h₁hₙ₋₁ + h₂hₙ₋₂ + … + hₙ₋₁h₁，正好是递推右边。这和"左边 K₁ 选一种、右边 K₂ 选一种"是同一回事。例：x⁴ 的系数是 h₁h₃ + h₂h₂ + h₃h₁ = 5 = h₄。

  1. 所以 g² = h₂x² + h₃x³ + h₄x⁴ + …（g² 的 x² 系数是 h₁h₁ = 1 = h₂，以后各项用递推）。这正是 g 去掉第一项：g² = g − h₁x = g − x。

9　指数生成函数（幻灯片 370–382）

为什么要除以 n!（幻灯片 370）

第6节的生成函数数的是"每种拿几个"，不管顺序。如果要数排成一列的方法，它就不对了。小例子：用最多 2 个 a、最多 1 个 b 排成长度为 n 的词。直接列：

  1. n = 1：a、b，2 个。
  2. n = 2：aa、ab、ba，3 个。
  3. n = 3：aab、aba、baa，3 个。

用第6节的方法：(1 + x + x²)(1 + x) = 1 + 2x + 2x² + x³，x² 的系数是 2，可实际有 3 个词。错在哪：2 数的是两种组合 {a, a} 和 {a, b}；但 {a, b} 能排成 ab、ba 两种，{a, a} 只有 1 种。一般地，m₁ 个 a 和 m₂ 个 b 的排列数是 (m₁+m₂)!/(m₁!·m₂!)（第3课多重集的排列）。

修正的办法：每个括号里写 xᵐ/m!，而不是 xᵐ：

(1 + x + x²/2!)(1 + x/1!) = 1 + 2x + (1/2 + 1)x² + (1/2)x³ = 1 + 2x + (3/2)x² + (1/2)x³

选 m₁ 个 a、m₂ 个 b 得到的那一项是 xm₁+m₂/(m₁!m₂!)，记 n = m₁ + m₂，它等于 [n!/(m₁!m₂!)]·xⁿ/n!：方括号里正好是排列数。所以要读 xⁿ/n! 的系数（也就是 xⁿ 的系数再乘 n!）：n = 2 时 (3/2)·2! = 3，n = 3 时 (1/2)·3! = 3，n = 1 时 2·1! = 2。全对了。

定义（幻灯片 370）：数列 h₀, h₁, h₂, … 的指数生成函数是

g⁽ᵉ⁾(x) = Σ hₙ·xⁿ/n! = h₀ + h₁x + h₂x²/2! + … + hₙxⁿ/n! + …

名字来自 eˣ = 1 + x + x²/2! + … + xⁿ/n! + …。

几个例子（幻灯片 371–372）

  1. P(n,0), P(n,1), …, P(n,n)：Σ P(n,k)·xᵏ/k! = Σ C(n,k)·xᵏ = (1+x)ⁿ。为什么：P(n,k)/k! = C(n,k)，有顺序的个数除以 k! 就是没顺序的个数。所以 (1+x)ⁿ 既是 C(n,k) 的普通生成函数，又是 P(n,k) 的指数生成函数。
  2. 1, 1, 1, …：Σ xⁿ/n! = eˣ。
  3. 1, a, a², …：Σ aⁿxⁿ/n! = Σ (ax)ⁿ/n! = eax。
  4. kⁿ（k 种字母、每种无限多个，长度 n 的词的个数）：ekx。核对 k = 2、n = 2：aa、ab、ba、bb，4 = 2² 个。每种字母一个括号 1 + x + x²/2! + … = eˣ，k 个相乘正是 ekx。

一般定理（幻灯片 373–376）

定理（7.39–7.40）：S = {n₁·a₁, n₂·a₂, …, nₖ·aₖ}，hₙ = S 的 n-排列数。则

g⁽ᵉ⁾(x) = fn₁(x)·fn₂(x)···fnₖ(x)，其中 fnᵢ(x) = 1 + x + x²/2! + … + xnᵢ/nᵢ!

为什么，和上面的小例子一模一样，只是字母多了：

  1. 乘开后，每一项是从每个括号挑一个 xmᵢ/mᵢ!（0 ≤ mᵢ ≤ nᵢ）相乘：xm₁+…+mₖ/(m₁!···mₖ!)（7.41）。
  2. 记 n = m₁ + … + mₖ，这一项 = [n!/(m₁!···mₖ!)]·xⁿ/n!。
  3. xⁿ/n! 的系数是所有这种 n!/(m₁!···mₖ!) 之和（7.42），对所有 m₁ + … + mₖ = n、0 ≤ mᵢ ≤ nᵢ 求和。
  4. n!/(m₁!···mₖ!) 正是"m₁ 个 a₁、……、mₖ 个 aₖ"排成一列的方法数。n-排列按"每种用了几个"分类，每类就是一项，所以总和就是 hₙ。

做题的规则：每种东西一个括号，括号里放 xᵐ/m!（m 取所有允许的个数），乘起来，读 xⁿ/n! 的系数。限制条件只改括号里留哪些项，和第6节一样。

  2. 偶数项怎么写成 e 的式子：e⁻ˣ = 1 − x + x²/2! − x³/3! + …，奇数次项带负号。和 eˣ 相加，奇数次项抵消、偶数次项加倍，所以 1 + x²/2! + x⁴/4! + … = (eˣ + e⁻ˣ)/2。（相减得奇数项：x + x³/3! + … = (eˣ − e⁻ˣ)/2。）

Solve the nonhomogeneous recurrence relation hₙ = 4hₙ₋₁ + 3 × 2ⁿ (n ≥ 1), h₀ = 1.

提示

2 不是特征根（特征根是 4），所以特解直接试 p·2ⁿ。

看答案
  1. 齐次通解 c·4ⁿ。
  2. p·2ⁿ = 4p·2ⁿ⁻¹ + 3·2ⁿ，除以 2ⁿ：p = 2p + 3，p = −3。
  3. hₙ = c·4ⁿ − 3·2ⁿ，h₀ = 1：c − 3 = 1，c = 4。hₙ = 4ⁿ⁺¹ − 3·2ⁿ。
  4. 核对：h₁ = 4 + 6 = 10 = 16 − 6；h₂ = 40 + 12 = 52 = 64 − 12。
#329　第4、5节

解非齐次递推 hₙ = 6hₙ₋₁ − 9hₙ₋₂ + 2n（n ≥ 2），h₀ = 1，h₁ = 0。

Solve the nonhomogeneous recurrence relation hₙ = 6hₙ₋₁ − 9hₙ₋₂ + 2n (n ≥ 2), h₀ = 1, h₁ = 0.

提示

齐次部分的特征根是二重根 3。bₙ = 2n 是一次式，1 不是特征根，特解试 rn + s。

看答案
  1. x² − 6x + 9 = (x − 3)²，齐次通解 (c₁ + c₂n)·3ⁿ。
  2. 特解 rn + s：rn + s = 6(r(n−1) + s) − 9(r(n−2) + s) + 2n = (−3r + 2)n + (12r − 3s)。比较 n 的系数：r = −3r + 2，r = 1/2；常数项：s = 12r − 3s，4s = 6，s = 3/2。
  3. hₙ = (c₁ + c₂n)·3ⁿ + n/2 + 3/2。n = 0：c₁ + 3/2 = 1，c₁ = −1/2。n = 1：3(c₁ + c₂) + 2 = 0，c₁ + c₂ = −2/3，c₂ = −1/6。
  4. hₙ = −(1/2 + n/6)·3ⁿ + (n + 3)/2 = (n + 3)(1 − 3ⁿ⁻¹)/2。
  5. 核对：h₂ = 6·0 − 9·1 + 4 = −5，公式 5·(1 − 3)/2 = −5；h₃ = 6·(−5) − 0 + 6 = −24，公式 6·(1 − 9)/2 = −24。
#334　第5节

解非齐次递推 hₙ = 4hₙ₋₁ + 4ⁿ（n ≥ 1），h₀ = 3。

Solve the nonhomogeneous recurrence relation hₙ = 4hₙ₋₁ + 4ⁿ (n ≥ 1), h₀ = 3.

提示

4 是特征根，"撞车"了，特解要乘 n。

看答案
  1. 试 p·4ⁿ 得 p = p + 1，不行。改试 p·n·4ⁿ：pn·4ⁿ = 4p(n−1)·4ⁿ⁻¹ + 4ⁿ，除以 4ⁿ：pn = p(n − 1) + 1，p = 1。
  2. hₙ = c·4ⁿ + n·4ⁿ，h₀ = 3 得 c = 3。hₙ = (n + 3)·4ⁿ。
  3. 核对：h₁ = 12 + 4 = 16 = 4·4；h₂ = 64 + 16 = 80 = 5·16。
#332　第6节

S = {∞·e₁, ∞·e₂, ∞·e₃, ∞·e₄}。hₙ 是 S 的满足下列附加条件的 n-组合数，分别求 h₀, h₁, … 的生成函数：(i) 每个 eᵢ 出现奇数次；(ii) 每个 eᵢ 出现 3 的倍数次；(iii) e₁ 不出现，e₂ 至多出现一次；(iv) e₁ 出现 1、3 或 11 次，e₂ 出现 2、4 或 5 次；(v) 每个 eᵢ 至少出现 10 次。

Determine the generating function for the sequence h₀, h₁, …, where hₙ is the number of n-combinations of S with the following added restrictions.

提示

每个 eᵢ 一个括号，括号里放允许的次数作指数；没提到的元素没有限制，括号是 1/(1−x)。

看答案
  1. (i) (x + x³ + x⁵ + …)⁴ = x⁴/(1 − x²)⁴。
  2. (ii) (1 + x³ + x⁶ + …)⁴ = 1/(1 − x³)⁴。
  3. (iii) e₁ 的括号是 1，e₂ 的是 1 + x，e₃、e₄ 各 1/(1−x)：(1 + x)/(1 − x)²。
  4. (iv) (x + x³ + x¹¹)(x² + x⁴ + x⁵)/(1 − x)²。
  5. (v) (x¹⁰ + x¹¹ + …)⁴ = (x¹⁰/(1−x))⁴ = x⁴⁰/(1 − x)⁴。
#338　第6节

一袋水果由苹果、橘子、香蕉、梨组成：苹果偶数个，橘子至多 2 个，香蕉是 3 的倍数个，梨至多 1 个。求 n 个水果的袋数 hₙ 的生成函数，并由它求 hₙ 的公式。

Determine the generating function for the number hₙ of bags of fruit of apples, oranges, bananas, and pears in which there are an even number of apples, at most two oranges, a multiple of three number of bananas, and at most one pear. Then find a formula for hₙ from the generating function.

提示

和幻灯片 341–342 的例子一样，写出四个括号后找能约掉的因子：1 − x³ = (1 − x)(1 + x + x²)。

看答案
g(x) = (1/(1−x²))·(1 + x + x²)·(1/(1−x³))·(1 + x)
(1 + x + x²)/(1 − x³) = 1/(1 − x)，(1 + x)/(1 − x²) = 1/(1 − x)
g(x) = 1/(1 − x)² = Σ (n + 1)xⁿ

hₙ = n + 1。核对 n = 2：2 苹果；2 橘子；1 橘子 + 1 梨，3 袋。

#335　第7节

求立方数列 0, 1, 8, …, n³, … 的生成函数。

Determine the generating function for the sequence of cubes 0, 1, 8, …, n³, ….

提示

从平方数的结果 x(1+x)/(1−x)³ = Σ n²xⁿ 出发，再做一次"求导、乘 x"，系数就再乘一个 n。

看答案
(x(1+x)/(1−x)³)′ = (1+2x)/(1−x)³ + 3x(1+x)/(1−x)⁴
= [(1+2x)(1−x) + 3x + 3x²]/(1−x)⁴ = (1 + 4x + x²)/(1−x)⁴ = Σ n³xⁿ⁻¹

再乘 x：x(1 + 4x + x²)/(1 − x)⁴。核对：x(1 + 4x + x²)(1 + 4x + 10x² + …) = x + (4+4)x² + (10+16+1)x³ + … = x + 8x² + 27x³ + …。

#343　第9节

求阶乘数列 0!, 1!, 2!, …, n!, … 的指数生成函数。

Determine the exponential generating function for the sequence of factorials: 0!, 1!, 2!, 3!, …, n!, ….

提示

直接写定义，n! 和 1/n! 会约掉。

看答案

Σ n!·xⁿ/n! = Σ xⁿ = 1/(1 − x)。（n! 是 n 个不同的东西的排列数；1/(1−x) 作为普通生成函数是 1, 1, 1, …，作为指数生成函数就是 n!。）

#347　第9节

用红、蓝、绿、橙给 1×n 棋盘涂色，红色格子偶数个，绿色格子也偶数个。有多少种涂法？

Determine the number of ways to color the squares of a 1-by-n chessboard, using the colors red, blue, green, and orange if an even number of squares is to be colored red and an even number is to be colored green.

提示

红、绿的括号是 (eˣ + e⁻ˣ)/2，蓝、橙是 eˣ。展开后注意 n = 0 那一项。

看答案
g⁽ᵉ⁾(x) = ((eˣ + e⁻ˣ)/2)²·e²ˣ = ((e²ˣ + 2 + e⁻²ˣ)/4)·e²ˣ = (e⁴ˣ + 2e²ˣ + 1)/4

xⁿ/n! 的系数是 (4ⁿ + 2·2ⁿ)/4，n = 0 时还要加上常数 1/4。所以 hₙ = 4ⁿ⁻¹ + 2ⁿ⁻¹（n ≥ 1），h₀ = 1。前几项 1, 2, 6, 20, 72。核对 n = 1：只能蓝或橙，2 种；n = 2：红红、绿绿，加上蓝、橙任意 4 种，共 6 种。

#348　第9节

各位数字都是奇数的 n 位数中，1 和 3 都出现非零的偶数次，这样的数有多少个？

Determine the number of n digit numbers with all digits odd, such that 1 and 3 each occur a nonzero, even number of times.

提示

和例 3（幻灯片 379–380）比，只是 1、3 的括号去掉了常数项 1：x²/2! + x⁴/4! + … = (eˣ + e⁻ˣ)/2 − 1。

看答案
g⁽ᵉ⁾(x) = ((eˣ + e⁻ˣ)/2 − 1)²·e³ˣ
((eˣ + e⁻ˣ)/2 − 1)² = (e²ˣ + 2 + e⁻²ˣ)/4 − (eˣ + e⁻ˣ) + 1
乘 e³ˣ：e⁵ˣ/4 − e⁴ˣ + (3/2)e³ˣ − e²ˣ + eˣ/4

hₙ = (5ⁿ − 4·4ⁿ + 6·3ⁿ − 4·2ⁿ + 1)/4。n = 0, 1, 2, 3 时都是 0（至少要两个 1 和两个 3）。核对 n = 4：(625 − 1024 + 486 − 64 + 1)/4 = 6，就是 1133 的 4!/(2!2!) = 6 种排法。n = 5 时是 90。
