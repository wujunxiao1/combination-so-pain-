1　有向图要沿箭头走

幻灯片 641–645

有向图 D = (V, A) 里的边叫弧。写成 (a, b) 或 a → b，表示从 a 出发、进入 b。a → b 和 b → a 是两条不同的弧。一般有向图还可以允许同方向的重弧，自环从同一点出发又回到该点。

出度 d+(x) 数从 x 出发的弧，入度 d−(x) 数到达 x 的弧。自环给两者各加 1。

∑d+(x) = ∑d−(x) = |A|

从每条弧来看，它给起点贡献一个出度，给终点贡献一个入度。

按箭头连着走叫有向途径。每条弧至多走一次叫有向迹，顶点也不重复时叫有向路。如果只允许首尾的顶点相同，就得到有向圈。

擦掉箭头后得到底图。底图连通就叫弱连通（讲义这里简称连通）。任意两个点顺着箭头都能互相到达才叫强连通。例如 a → b → c 的底图连通，但从 c 走不到 a。添上 c → a 后就强连通了。

有向 Euler 迹怎么判断？

有向 Euler 迹把每条弧恰好走一次。假设底图连通，数每个点进出是否平衡。

要找的迹充要条件
闭迹，回到起点每个顶点的入度等于出度。
从 x 出发，到 y 结束x 的出度比入度多 1，y 的入度比出度多 1，其余点入度等于出度。

走过中间点时，一进一出正好配平。起点多一次离开，终点多一次到达。以 a → b、b → c、a → c 为例。底图是一个三角形，a 却多了 2 个出度，因此既没有闭的 Euler 迹，也没有开的 Euler 迹。

度数配平以后，为什么一定能找到走法？

从一个有弧的点启程，总挑没用过的出弧。每个中间点只要能进入，一进一出的计数就保证还有下一条出弧，所以首次走不动时一定回到起点。如果还有弧没走，底图连通保证这条闭迹和剩下的弧有公共顶点。从那里用剩余的弧再走一圈，接到原迹上，重复到全部走完。

对于开迹，先临时补一条 y → x，把度数配平。找到闭迹后，从这条临时弧的后面开始读，并去掉临时弧，就得到从 x 到 y 的开迹。

有向 Hamilton 路要经过每个顶点恰好一次，Hamilton 圈还要回到起点。本节的度数平衡条件只用来判 Euler 迹。

2　竞赛图一定能排出一条 Hamilton 路

幻灯片 643、646

每两位选手打一次，胜者指向败者。这样给完全图 Kn 的每条边选一个方向，就得到竞赛图。若能把选手排成一列，使每人都打赢后面的所有人，叫传递竞赛图。一般竞赛图可能出现 a → b → c → a 的循环胜负。

对任意竞赛图，可以找到一列包含所有选手的顺序，使每人都打赢紧挨在后面的那个人。这条路就是 Hamilton 路。证明时，从只有一个点的路开始，把剩下的点一个个插进去。

怎么插点 x　从路的左端往右找第一个被 x 打赢的点 v，把 x 放在 v 前面。若 v 前面有点 u，因为 v 是第一个被 x 打赢的点，所以 u → x → v。如果一路找不到，路上的最后一个点打赢了 x，就把 x 接在末尾。

把 X 插到 A → B → C 中

图中显示旧路和插点用到的弧。换一组胜负，看看插入位置怎样变。

例如旧路为 A → B → C。若新点 X 输给 A 和 B，但赢了 C，第一个能接在 X 后面的点就是 C，于是得到 A → B → X → C。

讲义还有一个一般有向图的充分条件。对至少两个顶点的无自环强连通有向图，若每点的入度与出度之和都至少为顶点数 n，就存在有向 Hamilton 圈。竞赛图每点的这两个度数之和都是 n−1，竞赛图何时有 Hamilton 圈见 #574。

3　给道路定向时，先检查有没有桥

幻灯片 646–647

从无向连通图出发，给每条边恰好选一个方向。这叫给原图定向。想让定向后的图强连通，需要保证无论想去哪里，都有一条顺着箭头走的路。

强连通定向定理　一个连通无向图能做成强连通定向，当且仅当它没有桥。

桥是两块之间唯一的通道。无论桥指向何方，另一侧都无法沿箭头走回来。

无桥时，每条边都在某个圈上。先挑一个圈，让它的边都沿同一个方向走，得到一团已经互相可达的点 U。若还有点没进来，就选一条从 U 接到外面的边，并沿它所在的圈继续走，到第一次回到 U 为止。把这段路统一定向成 x → ⋯ → z。

  1. 旧点能到达 x，再向前走到每个新点。
  2. 新点能沿这段路走到 z，再走到每个旧点。
  3. 把新点加入 U。重复到全图都进来，剩下的边任意定向。

例　无向三角形 ABC 和 CDE 共用一个点 C。先定成 A → B → C → A，再沿 C → D → E → C 绕回来，最后五个点互相可达。

这个例子有割点 C，却没有桥。做本题时要检查删去一条边会不会断开。只有一个点时，直接满足强连通。

4　交易时，让每个人指向当前最想要的物品

幻灯片 648–653

每人带来一件物品，并且对所有物品有严格的偏好顺序。交易结束时，每人正好拿一件，每件也正好分给一人。用 ti → tj 表示「ti 拿 tj 原有的物品」。一份完整分配里每个点的出度、入度都是 1，所以全图拆成互不相交的有向圈。自己保留物品就画一个自环。

核心分配　按讲义的表述，找不到一组少于全体的交易者，仅用这组人原有的物品重新交换，就让组内每个人都比当前分配更满意。

最高交易圈（Top Trading Cycles）

  1. 每位还没交易的人指向他最想要的剩余物品的原主人。最想保留自己的物品，就指向自己。
  2. 从任意人出发不断跟着箭头走。每个点都有一条出弧，点又只有有限个，所以一定会回到某个走过的点。第一次重复围出来的那一段就是一个圈。
  3. 每个圈内的人都拿到自己箭头指向的物品。移除这些人及其物品，其他人重新指箭头。直到交易完毕。

第一轮　T1 → T3 → T4 → T1 构成一个圈，三人分别拿到物品 3、4、1。T2 指向 T3，T5 指向 T4。这两个人的箭头只是进入圈，他们要等下一轮。

第二轮　剩物品 2 和 5。T2 比较这两件时更喜欢 2，T5 更喜欢 5，因此二人各拿回自己的物品。按 T1 到 T5 的顺序，最终分配为 (3, 2, 4, 1, 5)。

为什么这是核心分配？ 假设有一组人能私下重换，让每个人都严格变好。从组里挑一位在算法中最早交易的人。当他离场时，这组人的原有物品都还在那一轮的候选范围内，包括同一轮离场的人的物品。他已经拿到了自己最喜欢的剩余物品，因此靠这组人的物品无法让他变得更满意。

5　最大流最小割：能送多少，哪里卡住？

幻灯片 654–661

把水管画成有向弧。源点 s 供水，汇点 t 收水。弧 e 的容量 c(e) 是它最多能运多少，流量 f(e) 是实际安排它运多少。一组流量是否合法，要检查两件事。

  1. 每条弧满足 0 ≤ f(e) ≤ c(e)。
  2. 除 s、t 外，每个点的流入总量等于流出总量。这叫流量守恒。

流值是从 s 净流出的总量，也等于流入 t 的总量减去从 t 流出的总量。做题时只算这一个净值。

画一道分界线，就能给流值一个上界

挑一个包含 s 且不包含 t 的顶点集 U。从 U 指向外面的所有弧组成一个割，记作 δ+(U)。每条 s 到 t 的路都得向外跨界至少一次。割容量只加向外的弧的容量。

流值 = 向外跨界的流量 − 向内跨界的流量 ≤ 向外弧的容量和

为什么等号左边是流值？对 U 里的点逐个算「流出减流入」。内部弧在两端各算一次，正负抵消。除了源点以外的点净流出都是 0，所以剩下的正好是源点的净流出。

最大流最小割定理　网络的最大流值等于最小割的容量。要证明某个流已经最大，只需给出一组合法流和一个容量等于该流值的割。

讲义把任何截断所有 s 到 t 路径的弧集都叫割。把这些弧临时删掉，从 s 还能到达的点组成 U，则 δ+(U) 中的每条弧都在原弧集内。因此找最小割时可以直接找这样的分界。这里的「最小」比较容量和。

增广路：既能加流，也能撤回旧流

如果一条弧没装满，沿原方向还可以增加流量。如果它已经送了一些流，也可以撤回一部分，把容量让给别的路线。把这两种可调整的方向画成残量网络。

原弧 u → v残量弧沿它增广 Δ 时
还剩 c−f 的容量u → v，残量 c−f原弧流量加 Δ。
原来已经送了 fv → u，残量 f原弧流量减 Δ。

在残量网络找一条从 s 到 t 的路。取路上最小的正残量作为 Δ，沿路更新原弧，没经过的弧保留原流量。这叫增广。反向走一步等于减小对应原弧上的流量。增广后中间点流量仍然守恒，整个流值增加 Δ。

亲手撤销一段旧流量

初始五条弧的容量都是 1。原图用「流量 / 容量」标注，看到残量网络时只标还能调整的量。

手算例题　五条弧容量都是 1，分别为 s → a、s → b、a → b、a → t、b → t。

  1. 先沿 s → a → b → t 送 1。此时 b → t 已满，s → b 虽然还空着，却接不上直接去 t 的路。
  2. 在残量网络选择 s → b → a → t，中间的 b → a 是反向弧。给 s → b、a → t 各加 1，把 a → b 减为 0。
  3. 最终等同于各送 1 沿 s → a → t 和 s → b → t。割 U = {s} 的容量是 2，正好等于流值，所以已经最大。

找不到增广路时，怎样读出最小割？

从 s 沿正残量弧能到的所有点组成 U，这时 t 不在里面。每条原图中向外跨界的弧一定满了，有剩余容量的话还能到达界外。每条从外面指回 U 的原弧一定是零流量，有流量的话还能沿反向残量弧走到界外。因此流值等于这个割的容量，二者同时达到最优。

容量是整数时，从零流开始，每次可增加一个正整数，流值又有上界，所以有限步后停止，并得到一个整数最大流。讲义的基本算法每次加 1，取路径上的最小残量可以一次多加一些。对实数容量，可以从一个最大流出发应用同样的可达集论证。

同一个定理还能用来找路和做匹配

弧不相交的路　给每条弧容量 1。整数流里每条弧最多用一次，把流拆成从 s 到 t 的路，绕回来的圈不影响流值。因此最多能找多少条两两不共用弧的路，等于最少要删几条弧才截断 s 到 t。

二部图匹配　回到第 9 课的左右两组。加上源点和汇点，从 s 到每个左点、从每个右点到 t 各连容量 1 的弧。原边从左指向右，容量设得比左侧点数还大。一个单位的整数流经过一组配对，源点边和汇点边的容量保证每个点至多参加一次。最小割容量至多等于左侧点数，因此割不会切到原配对弧。取割外的左点和割内的右点，就能盖住每条原边，个数也等于割容量。这给出 König 定理里的最大匹配数等于最小顶点覆盖数。

#568　证明竞赛图是传递的，当且仅当它没有三点有向圈。

展开解答

如果能从强到弱排成一列，弧都由前指向后，无法绕回起点。反过来，若 a → b 且 b → c，则必须 a → c，因为 c → a 会构成三点圈。这样胜负关系既能比较任意两人，又具有传递性，可以排成一列。

#570　证明没有有向圈，当且仅当可以编号 1 到 n，使每条弧的终点编号大于起点编号。

展开解答

如果沿弧编号严格增大，就不可能绕回原点。反过来，无圈图必有一个入度为 0 的点。若每个点都有入弧，就可以沿入弧反向一直追，有限个点必然重复，追出来一段有向圈。把入度 0 的点编号为 1 后删掉，剩下仍无圈，再找入度 0 的点编号 2。照做直到取完。这种编号叫拓扑排序。

#574　证明在至少有三个点的竞赛图中，强连通等价于存在有向 Hamilton 圈。

展开解答

有 Hamilton 圈时，沿圈可以从任何点走到其他点，所以强连通。反过来，在强连通竞赛图里取一个最长有向圈。圈外若有个点 x 既输给圈内某点也赢过圈内某点，那么沿圈走一周，总能找到相邻的 u → v，其中 u 赢 x、x 赢 v。插入 x 就把圈变长了。

因此每个圈外点要么被圈上所有点打败（记入 A），要么打败圈上所有点（记入 B）。若圈外还有点，强连通迫使两类都非空，还迫使有一条 a → b（a ∈ A，b ∈ B），否则从 A 中出发就出不了 A。把圈上任一条 u → v 换成 u → a → b → v，又得到更长的圈，矛盾。所以最长圈已覆盖全体顶点。

#587　根据习题集中的七人偏好表，求一份核心分配。

展开解答
  1. 第一次的箭头终点按 T1 到 T7 排是 (3, 1, 5, 5, 1, 3, 5)。圈是 T1 → T3 → T5 → T1，这三位先交换。
  2. 剩下 T2、T4、T6、T7。他们分别指向 T4、T2、T2、T4。T2 和 T4 互换。
  3. 只剩 T6 和 T7 时两人都指向 T7。T7 留下自己的物品。最后 T6 也保留自己的物品。

最终物品分配按 T1 到 T7 排为 (3, 4, 5, 2, 1, 6, 7)。

#589　求习题集里三个网络各自的最大流和最小割。

展开解答

下面每条路后面的数字是沿整条路送出的量。重叠的弧把用量相加，没用到的弧记为 0。读出合法流后，再用等容量的割证明它最大。

左图，流值 9　左上、左下、右上、右下四个中间点分别记作 A、B、C、D。
